Windows용 쇼 큐 플레이어

최신 버전 다운로드

Windows 10/11 64비트 · 설치 파일은 GitHub 릴리스에서 받습니다.

설치 파일에 아직 코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 경고 창에서 추가 정보 → 실행을 누르면 설치가 진행됩니다.

기능

큐 리스트와 그룹

번호·이름·파일·길이가 보이는 리스트에 파일이나 폴더를 끌어다 놓으면 큐가 됩니다. 타임라인 그룹(자식 동시 시작)과 플레이리스트 그룹(차례로 재생)을 지원합니다.

GO, 페이드, 전체 정지

스페이스 바 GO, 일시정지, 페이드아웃, Esc 전체 페이드 정지(초 단위 설정). 프리웨이트·포스트웨이트로 큐 사이 간격을 잡습니다.

재생 탭

파형에서 트림·루프 구간을 잡고, 엔벨로프 점을 끌어 페이드 곡선을 그리면 재생 중에도 바로 들립니다. 파형을 누르면 그 위치부터 재생됩니다.

레벨과 출력 라우팅

큐마다 게인과 16개 큐 출력 매트릭스. ASIO 장치에서는 최대 64개 출력을 쓰고, Windows Audio 모드에서는 출력 1-2로 재생합니다.

VST3 플러그인

큐별, 출력 패치별, 마스터 버스에 플러그인 체인을 걸 수 있습니다. 제조사별 메뉴, 순서 바꾸기, 활성·비활성 전환.

고품질 리샘플링

곡 샘플레이트가 장치와 달라도 r8brain 리샘플러가 정확한 피치와 음질로 변환합니다.

마이크 큐

오디오 인터페이스 입력을 큐로 올려 방송·행사 진행에 쓸 수 있습니다.

세션과 백업

세션은 .gocue 파일 하나. 음원은 프로젝트 폴더로 복사되고, 5분마다 자동 백업이 15개까지 남습니다. 자동 업데이트를 지원합니다.

요구 사항

운영체제
Windows 10 / 11 (64비트)
오디오 장치
ASIO 인터페이스 권장. 다채널 출력은 ASIO에서만 됩니다. Windows Audio(공유/독점/저지연)와 DirectSound는 출력 1-2.
플러그인
VST3
설치
사용자 계정에 설치(관리자 권한 불필요). 업데이트는 프로그램 안에서 자동으로 확인합니다.

베타 참여

지금은 베타 기간입니다. 문제나 의견은 오픈채팅으로 보내 주세요. 프로그램 안 도움말 → 베타 피드백 메뉴에서도 열립니다.

오픈채팅 주소는 곧 공개됩니다.

사용 설명서는 프로그램 안 도움말 → 사용 설명서(Ctrl+F1)에 있습니다.
