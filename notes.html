바뀐 점

버전별 변경 사항. 최신 버전이 맨 위입니다.

Enqueue 0.9.5

  • 유튜브다운 메뉴. 유튜브 링크를 넣으면 이 PC에서 소리만 받아 mp3(320 kbps)로 만들어 저장합니다. "다운받고 큐에 넣기"를 켜 두면 받자마자 큐로 들어갑니다. 저장 위치: 내 문서\Enqueue\유튜브다운. 유튜브 쪽이 바뀌어 안 받아지면 다운로드 도구(yt-dlp)가 스스로 최신으로 갱신하고 다시 시도합니다.
  • 큐 리스트에서 큐를 그룹 행 위(가운데)에 놓으면 그 그룹 안으로 들어갑니다(접힌 그룹도). 그룹을 접으면 안의 큐가 숨고 펼치면 다시 보입니다.
  • 그룹 탭의 안내 문구("막대를 끌어 자식의 시작...")를 없앴습니다.

Enqueue 0.9.4

공연 안전성 점검 결과를 반영하고, 페이드 큐를 단순하게 바꾼 버전입니다.

바뀐 사용법

  • 페이드 큐가 "페이드 인"과 "페이드 아웃" 두 가지로 바뀌었습니다. 페이드 인 큐(Ctrl+7)를 실행하면 대상 큐가 무음에서 시작해 설정한 시간 동안 원래 레벨까지 올라갑니다(이미 재생 중이면 지금 레벨에서 올라갑니다). 페이드 아웃 큐(Ctrl+Shift+7)를 실행하면 대상이 설정한 시간 동안 무음까지 내려간 뒤 정지합니다. 설정은 대상·종류·시간(페이드 탭)과 모양(커브 탭)뿐이고, 트리거·파라미터 탭은 페이드 큐에서 없앴습니다. 이전 버전에서 만든 페이드 큐는 "사용자 지정"으로 그대로 동작합니다.
  • 메인 큐 리스트에서 마우스 오른쪽 버튼을 누르면 큐 추가 항목이 바로 나옵니다. 빈 곳에서 눌러도 나옵니다.
  • 오디오 파일을 그룹 큐 위에 끌어다 놓으면 그 그룹 안으로 들어갑니다. 그룹 행의 가운데에 놓으면 그룹의 마지막 자식이 되고(그룹이 접혀 있으면 펼쳐짐), 행 사이에 놓으면 지금처럼 그 자리에 들어갑니다.
  • "아밍(활성)"과 "비활성이면 건너뛰기"가 "비활성화" 스위치 하나로 합쳐졌습니다. 켜면 그 큐는 재생되지 않고 GO와 시퀀스가 그냥 지나갑니다. 우클릭 메뉴의 활성화/비활성화도 같은 스위치입니다.

안전성

  • 전체 정지(Esc)가 어떤 경우에도 소리를 끕니다. 플러그인이 잔향을 계속 내거나 다른 작업이 엔진을 붙잡고 있어도 출력단 마지막에 있는 게이트가 닫힙니다. 즉시 정지(Esc 두 번)는 어떤 락도 기다리지 않고 바로 무음이 됩니다.
  • 페이드 정지가 진행되는 동안에는 GO·핫키·시간 트리거가 시작되지 않습니다. 정지 중에 눌린 GO가 페이드가 끝난 뒤 혼자 남아 재생되는 일이 없습니다. 전체 정지 뒤 플러그인 잔향을 지우는 처리가 끝나기 전에는 엔진도 시작을 받지 않고 이유를 알려 줍니다(큰 버퍼에서도 잔향이 살아남지 않음).
  • 페이드 정지 중에 이미 잔향만 남아 울리던 큐는 뚝 끊기지 않고 같은 시간 동안 같이 줄어듭니다. 즉시 정지(Esc 두 번)는 그대로 바로 끊습니다.
  • 플러그인이 오류를 내도 소리가 끊기지 않습니다. 예외를 낸 플러그인은 그 자리에서 우회되고 나머지는 계속 재생됩니다.
  • Esc(전체 정지)가 어느 창에서든 동작합니다. VST 플러그인 자체 창·설명서·설정 창이 앞에 있어도 재생 중이면 Esc로 전체 정지가 됩니다(대화 상자의 Esc 취소도 그대로 동작). Space(GO)는 플러그인 창·설명서에서도 동작하며, 키를 누르고 있어도 한 번만 실행됩니다. 인스펙터의 모든 입력칸에서 Esc는 편집을 취소하고 전체 정지를 실행합니다.
  • 쇼 모드 잠금이 넓어졌습니다. 쇼 모드에서는 새 프로젝트·열기·프로젝트 설정·오디오 출력 설정·패치·플러그인 관리·업데이트 확인·리스트 탭 전환·진행 막대 클릭 이동이 잠깁니다. 재생 중이거나 쇼 모드일 때 종료·다른 프로젝트 열기는 한 번 더 확인합니다.
  • 핫키 검증. 다른 곳에서 만든 프로젝트에 Space·Esc 같은 앱 예약 키나 중복 핫키가 들어 있으면 불러올 때 지우고 알려 줍니다. 한 키는 한 큐만 재생합니다.
  • 저장이 더 안전해졌습니다. 옆에 임시 파일로 먼저 쓰고 크기와 내용을 검증한 뒤 바꿔 넣습니다. 디스크가 꽉 차거나 네트워크 드라이브가 끊겨도 이전 파일은 그대로 남습니다. 빈 파일·깨진 파일·다른 앱의 JSON은 프로젝트로 열지 않습니다. 저장(Ctrl+S)은 입력 중인 칸을 먼저 확정합니다. 자동 백업은 재생 중·쇼 모드에서는 쉬었다가 한가할 때 합니다.
  • 쇼 폴더를 통째로 복사하면 같이 복사된 음원을 씁니다. 원래 위치의 파일이 아직 있어도 프로젝트 옆에 있는 사본이 우선입니다.
  • 오디오 장치가 열려 있지 않으면 큐가 시작되지 않고 이유를 알려 줍니다. 저장된 출력 장치를 열지 못해 다른 장치로 열렸으면 시작할 때 경고합니다. 동시 재생은 256개까지입니다.
  • 안전 모드. Shift를 누른 채 실행하거나 --safe-mode로 실행하면 저장된 오디오 장치와 플러그인을 불러오지 않고 시작합니다. 드라이버나 플러그인 때문에 창이 뜨지 않을 때 쓰세요.
  • 업데이트로 재시작하면 열려 있던 프로젝트를 다시 엽니다. 업데이트 서명 키가 확인되지 않으면 업데이트 기능은 꺼집니다.
  • WMA 파일을 재생합니다. Windows N 에디션처럼 미디어 구성 요소가 없는 PC에서도 앱은 정상 실행됩니다(그 파일 형식만 열리지 않습니다).
  • 페이드·디밴프·컨트롤 큐의 대상 큐 목록에서 긴 이름이 찌그러지지 않고 말줄임으로 표시되며, 페이드 큐의 대상 칸은 남는 폭만큼 넓어집니다.
  • 설치 프로그램은 Windows 10(1607) 이상에서만 설치됩니다.

Enqueue 0.9.3

  • 무한 루프·재생 횟수가 재생 중에 바로 적용됩니다. 재생 중인 큐에서 무한 루프를 켜면 그 자리에서 계속 돌고, 끄면 지금 도는 회차를 끝까지 재생한 뒤 멈춥니다. 재생 횟수 숫자를 바꿔도 즉시 반영됩니다(전에는 정지 후 다시 재생해야 했습니다). 실행 취소로 되돌려도 재생 중인 큐에 같이 적용됩니다.

Enqueue 0.9.2

  • 글씨가 커졌습니다: 메인 큐 리스트 18pt(행도 더 높게), 큐 인스펙터의 항목 이름 15pt·설명 13~14pt, 재생·레벨·플러그인·커브 탭과 리스트 탭도 같이. 인스펙터 최소 높이가 조금 커졌습니다.

  • 그룹 타임라인의 시간 글자 잘림, 재생 탭 첫 줄이 최소 창 폭에서 밀리던 것, 플러그인 슬롯 이름 폭을 손봤습니다.

Enqueue 0.9.1

Enqueue 0.9.0

  • 이름이 바뀌었습니다: GoCue → Enqueue(앤큐), 만든 곳은 곰튀김. 설치 파일은 기존 GoCue 위에 그대로 덮어 설치되고(제자리 업그레이드), 설정과 플러그인 목록은 첫 실행 때 자동으로 옮겨집니다. 프로젝트 파일은 .enqueue이고 예전 .gocue 파일도 그대로 열립니다(더블클릭 포함). 예전 파일을 저장하면 이름은 그대로 둡니다.
  • 설치 때 쿠팡 바로가기 옵션(체크박스, 기본 켜짐): 바탕화면에 쿠팡 바로가기를 만듭니다. 쿠팡 파트너스 링크라 구매가 있으면 곰튀김에 일정액의 수수료가 갑니다. 원하지 않으면 체크를 끄거나 바탕화면에서 지우면 됩니다. 자동 업데이트는 지운 바로가기를 다시 만들지 않습니다.
  • 도움말 → 커뮤니티: 카카오톡 오픈채팅이 열립니다. 문제나 의견은 여기로.
  • 정보 창 문구 정리.

GoCue 0.8.9

  • 다채널 출력은 ASIO에서만: Windows Audio(공유/독점/저지연)와 DirectSound에서는 출력 1-2만 열립니다. 저장돼 있던 다채널 설정도 그 모드에서는 처음부터 1-2로 열리고, 장치가 넓은 요청을 거부하면 1-2로 다시 시도합니다. 오디오 출력 설정의 채널 목록은 ASIO에서만 보이고, 다른 모드에는 안내 문구가 붙습니다.
  • 장치가 채널 구성만 바꿔 다시 열릴 때(모드 전환 등) 재생 중인 큐가 끊기거나 몇십 ms를 건너뛰지 않습니다. 다시 열기에 실패하면 안내 창이 뜹니다.

GoCue 0.8.8

  • 프로젝트 파일 열기: GoCue가 떠 있는 상태에서 .gocue 파일을 더블클릭하면 새 창이 하나 더 뜨지 않고, 떠 있던 창이 그 프로젝트를 엽니다(저장 안 한 변경이 있으면 먼저 묻습니다). 창이 최소화돼 있으면 앞으로 나옵니다.

GoCue 0.8.7

  • 고품질 리샘플러: 파일과 장치의 샘플레이트가 다를 때(예: 48k 파일 → 44.1k ASIO) 이제 r8brain(윈도우드 싱크, 선형 위상, 21 kHz까지 평탄, 앨리어싱 -140 dB 이하)으로 변환합니다. 전에는 선형 보간이었습니다. 같은 샘플레이트면 변환 없이 그대로 통과합니다.
  • 재생 탭 페이드 엔벨로프 실시간 반영: 재생 중에 점을 움직이거나 사용/직선/잠금을 바꾸면 바로 들립니다(전에는 다음 재생부터).

GoCue 0.8.6

  • 앱 안 자동 업데이트(무음 설치)가 끝나면 앱이 스스로 다시 실행됩니다.

GoCue 0.8.4

  • WASAPI exclusive 모드 멀티 채널: 장치의 채널 수를 찾을 때와 열 때 표준 스피커 배치(5.1 = 0x3F/0x60F, 7.1 = 0x63F/0xFF 등)와 "배치 없음" 마스크도 시도합니다. 지금까지는 "앞에서부터 N채널" 마스크만 시도해 exclusive 모드에서 드라이버가 거부하면 스테레오만 나왔습니다. (JUCE 수정: tools/juce-patches/0001-wasapi-exclusive-channel-masks.patch)
  • 테스트 실행 파일에 장치 점검 항목(GOCUE_PROBE_DEVICES=1)을 넣어 장치별 채널 수와 열기 결과를 찍어 볼 수 있습니다.

GoCue 0.8.3

  • 새 디자인 "큐랩 스타일"(시안 10번): 중간 회색 바탕, 파란 선택, 초록/주황/노랑 상태색, 5 px 모서리와 옅은 그라데이션 버튼. 레이아웃은 그대로입니다.
  • 재생 중 행은 어두운 초록, 일시정지 행은 어두운 노랑, 페이드 중 행은 어두운 주황이고 아이콘·진행 막대·활성 큐 막대는 밝은 상태색입니다.
  • 설치 프로그램이 "모든 사용자 / 현재 사용자"를 묻지 않고 바로 현재 사용자용으로 설치합니다.
  • 메뉴 글자 18 pt(항목 높이도 같이), 메뉴 막대 17 pt.
  • 큐 리스트: 글자 16/15 pt, 번호는 이름처럼 굵게, 행이 조금 높아졌습니다. 번호를 바꾸면 그 번호 순서에 맞는 자리로 자동으로 옮겨집니다(같은 그룹 안에서).
  • 재생 탭: 파형을 클릭하면 그 위치부터 바로 재생(재생 중이면 그 위치로 건너뜀). 확대 +/-(Ctrl+휠도 됨)와 파형 세로 크기 +/- 버튼. 전체 보기 / 구간에 맞춰 줌은 우클릭 메뉴에.

  • 진행 · 시퀀스: 큐마다 프리웨이트/포스트웨이트, 진행 모드(계속 안 함 / 자동 계속 / 자동 팔로우). GO 한 번에 묶인 시퀀스가 차례로 재생되고 플레이헤드는 시퀀스 다음으로 이동. 플레이헤드와 선택을 분리하거나 잠글 수 있음.
  • 트리거 탭: 큐 핫키, 시간(벽시계) 트리거(요일 선택), 시작할 때 다른 큐 페이드 정지(범위: 주변/리스트/전체), 덕(재생 중 다른 큐를 -dB로 낮췄다가 끝나면 복원).
  • 로드: L = 큐를 미리 로드(GO 지연 0), Ctrl+T = 시간으로 로드(음수 = 끝에서부터), 자동 로드 옵션.
  • 활성 큐 패널(Ctrl+L): 재생 중인 큐마다 일시정지/재개 · 경과/남은 시간 · 진행바(드래그로 위치 이동) · 페이드 정지 버튼.
  • 쇼 모드(Ctrl+Shift+M, 푸터 버튼): 공연 중 편집 잠금(추가·삭제·이동·속성 편집 차단, 재생·저장은 그대로).
  • 편집: 큐 복사/잘라내기/붙여넣기(Ctrl+C/X/V, 플러그인 체인 포함), 큐 속성 붙여넣기(Ctrl+Shift+V: 기본·시간·트리거·시간루프·레벨·이펙트 골라서), 찾기(Ctrl+F, F3 다음), 선택 큐를 새 큐 기본값(템플릿)으로 저장.
  • 경고 · 파일 다시 찾기: 푸터의 경고 수 클릭 → 문제 있는 큐 목록, 큐 > 없어진 파일 찾기로 다른 폴더의 같은 이름 파일에 재연결.
  • 프로젝트 설정: 열 때/닫을 때 큐 시작(닫을 때 큐는 끝난 뒤 종료), 자동 번호·증가, 플레이헤드 잠금, 행 크기.
  • 프로젝트 파일 형식은 v2 그대로(새 필드만 추가). 0.2.0 파일은 그대로 읽힘.

GoCue 0.2.0

큐랩(QLab) 오디오 기능 이식 1단계.

  • 파형 편집: 인스펙터 "시간·루프" 탭에 파형 표시. 아래 회색 핸들로 시작/끝 트림(재생 중에도 즉시 반영), 노란 선을 클릭해 페이드 엔벨로프 점 추가·드래그, 재생 횟수/무한 루프, 속도, 줌, 미리듣기(V).
  • 키 체계 변경: Space = GO(일시정지된 큐가 있으면 재개), P = 일시정지/재개, F = 페이드아웃 정지, Esc = 전체 페이드 정지(기본 2초, 0.5초 안에 두 번 = 즉시). S 키와 "전체 정지" 버튼은 없앴습니다.
  • 실행 취소 / 다시 실행 (Ctrl+Z / Ctrl+Y, 200단계, 플러그인 추가/삭제/바이패스 포함).
  • 드래그앤드롭: 오디오 파일·폴더를 창 어디에나 놓으면 큐로 추가, 인스펙터 파일칸에 놓으면 파일 교체, .gocue 파일은 열기.
  • 2차 트리거: 재생 중 같은 큐에 GO가 오면 무시/페이드 정지/즉시 정지/재시작/이번 반복만 마치기 중 선택(트리거 탭). 프로젝트 설정에서 "GO 사이 최소 시간"(더블 GO 방지)과 "키를 뗀 뒤에만 다시 GO".
  • 자동 백업: 프로젝트 옆 <이름>.gocue.backups 폴더에 주기 백업·저장 전 백업·자동 정리. 큐 추가 시 파일을 프로젝트 폴더로 복사하는 옵션.
  • 고침: 재생 중에 게인을 바꿔도 소리에 반영되지 않던 문제. 프로젝트를 열자마자 "수정됨(*)"이 붙던 문제.
  • 프로젝트 파일 형식 v2 (이전 파일도 그대로 읽힘: 페이드인은 엔벨로프로 바뀜).
