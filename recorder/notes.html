Recorder (가칭) 0.1.5

붙이기, 오디오 파일 불러오기, 마이크 입력 설정을 고쳤습니다.

  • 클립 붙이기: 옆 클립에 갖다 대면 틈 없이 정확히 붙습니다. 지금까지는 붙였다고 보여도 프로젝트 프레임 격자로 다시 반올림되면서 최대 반 프레임(60fps에서 8ms)이 어긋났고, 그 틈이 재생할 때 검은 화면으로 보였습니다. 자석이 걸리는 범위도 넓혔고(12픽셀 또는 1.5프레임), 붙으면 아래 상태줄에 "이웃 클립에 붙임"이라고 나옵니다. 1프레임보다 작은 틈이나 겹침은 자동으로 0으로 맞춥니다. Alt를 누르거나 스냅을 끄면 예전처럼 마우스 위치 그대로입니다.
  • 오디오 파일 불러오기: 상단 "오디오 불러오기" 버튼(더빙과 설정 사이) 또는 창에 파일을 끌어다 놓으면 WAV·MP3·M4A·AAC를 가져와 타임라인에서 바로 들을 수 있습니다. 놓이는 위치는 타임라인 화면에서는 재생헤드, 녹화 화면에서는 타임라인 끝입니다. 컷편집·저장·다시 열기·소재 내보내기까지 됩니다. 프로젝트와 샘플레이트가 다르면 재생용으로 변환하고 원본은 그대로 둡니다.
  • 마이크 입력 설정: 입력 선택과 모노/스테레오를 나눴습니다. 슬롯마다 물리 입력을 고르고 옆에서 모노·스테레오를 누르면 되고, "마이크 1 · 입력 1+2 (스테레오)"처럼 현재 상태가 한 줄로 보입니다. 다른 마이크가 이미 쓰는 입력은 목록에서 막히고 어느 슬롯이 쓰는지 알려 줍니다. 마지막 입력에서는 스테레오를 고를 수 없습니다. 8슬롯은 두 페이지로 나뉩니다.

Recorder (가칭) 0.1.4

0.1.3에 이어 컷편집 안정성, 타임라인과 영상 위치 정렬, 컷 이음새, 마이크 스테레오, 타임라인 녹화, 단축키를 넣었습니다.

  • 컷편집 튕김: 시작점이 0인 클립을 왼쪽으로 끌면 거부된 편집의 미리보기가 잘못된 범위를 만들어 앱이 종료되던 경로를 막았습니다. 드래그·미리보기·스냅 계산은 범위를 넘지 않게 바꾸고, 화면과 문서가 어긋난 클릭, 재생 준비 작업의 예외, 프로젝트 교체 뒤 도착한 파형·썸네일 결과도 안전하게 처리합니다. 예상치 못한 오류는 앱을 끝내지 않고 crash 폴더에 기록한 뒤 알려 줍니다. 실제 미디어로 컷편집 312회 무작위 스트레스와 음수 드래그 26회를 통과했습니다.
  • 타임라인 위치와 실제 영상: 타임라인·스크럽 썸네일이 0.5초 단위로 내림돼 재생 위치와 최대 29프레임 어긋나던 것, 재생 영상이 오디오·플레이헤드보다 1프레임 앞서던 것, 녹화 시 프레임 선택이 평균 15ms 이르던 것을 고쳤습니다. 실측에서 영상·썸네일·오디오 위치 오차 0입니다. (이미 녹화된 파일의 15ms 오차는 그대로입니다.)
  • 컷 이음새: 컷편집으로 붙인 자리에서 검은 화면이 잠깐 나오던 것을 다음 클립 첫 프레임을 미리 준비해 두고 마지막 프레임을 유지하는 방식으로 없앴습니다.
  • 마이크 스테레오: 설정의 마이크 입력에서 "1+2 · 이름/이름 (스테레오)"처럼 인접한 두 입력을 한 슬롯으로 잡으면 2채널 24bit WAV 하나로 녹음됩니다. 재생·컷편집·복구·소재 내보내기(스테레오 WAV 하나)·최종 MP4까지 L/R을 유지합니다. 기본은 모노이고 기존 설정·프로젝트는 그대로 열립니다. 저장에 실패한 마이크 구간은 무음으로 재생됩니다.
  • 타임라인을 띄운 채 녹화: 타임라인 화면에서도 캠1·캠2 미리보기와 녹화 시작/정지/마커 버튼이 유지되고, 녹화 중에는 실제로 녹화 중인 카메라·마이크 자리에 자라는 빨간 임시 클립이 보입니다. 정지하면 실제 클립으로 바뀝니다.
  • 드래그 느낌: 4px 이상 움직여야 편집이 시작되고(살짝 움직이면 선택만), 이동·트림 고스트와 스냅 안내선, 클립 경계·마커·재생헤드 자석 스냅, 화면 가장자리 자동 스크롤, Esc 취소, Ctrl+휠은 마우스 위치 기준 확대, Shift+휠 가로 이동.
  • 단축키: 설정의 단축키 탭에서 녹화 시작(F9)·녹화 정지(F10)·재생/정지(Space)·스플릿(S)·마커(M)를 바꿀 수 있습니다. 내보내기·설정 창에 포커스가 있어도 녹화 정지는 동작하고, 글자 입력 중에는 동작하지 않습니다.
  • 설정 창: 오디오 설정이 거부되면 화면이 마지막 적용값으로 되돌아가고, 동기 보정 표시는 입력 매핑까지 포함한 실제 판정을 따릅니다.

Recorder (가칭) 0.1.3

0.1.2 자동 업데이트로 받는 첫 버전입니다.

  • 샘플레이트: 아직 미디어(녹음·가져온 오디오)가 없는 프로젝트는 오디오 장치의 샘플레이트를 그대로 따라갑니다. 첫 미디어 뒤에 장치가 다른 속도로 열리면 프로젝트·장치 숫자를 함께 보여주고, 장치 쪽에서 맞춘 뒤 설정에서 적용을 누르면 다시 연결합니다.
  • 카메라 입력 모드: "MJPEG 1920x1080 5/1" 같은 표기를 "1080p 30fps · MJPEG"로 바꾸고, 카메라를 고르면 프로젝트 fps에 맞는 모드가 자동으로 선택됩니다. 5fps 같은 저속 모드가 저장돼 있으면 설정을 열 때 다시 고르고, 적용을 누르면 저장됩니다.
  • 타임라인 우클릭 메뉴가 마우스 위치에서 열립니다.
  • 비정상 종료 시 설정 폴더의 crash 폴더에 덤프와 보고 파일을 남기고(메모리가 심하게 손상된 경우엔 남지 않을 수 있음), 다음 실행에서 파일 이름과 폴더 열기 버튼을 보여줍니다.

Recorder (가칭) 0.1.2

내부 배포 버전입니다. 이제 앱이 새 버전을 스스로 확인해 설치합니다.

  • ASIO 자동 연결: "장치 연결" 버튼을 없앴습니다. 설정에서 고르는 즉시 적용되고, 처음 실행하면 이 PC의 첫 ASIO 드라이버를 잡아 마이크 1은 입력 1, 재생은 출력 1/2로 시작합니다.
  • 오디오 장치 실패가 카메라를 끊지 않습니다. 카메라 설정이 그대로면 오디오만 바꿔도 미리보기가 유지됩니다.
  • 앱 내 업데이트: 실행 20초 뒤와 하루 한 번 새 버전을 조용히 확인하고, 있으면 안내 후 설치합니다. 녹화·더빙·내보내기 중에는 확인도 설치도 하지 않습니다. 정보 화면의 업데이트 확인 버튼도 동작합니다.
  • 0.1.1: 벤더 ASIO 드라이버(Apartment 모델 COM)를 메시지 스레드에서 열도록 고쳐 "ASIO requires an output callback…" 오류를 해결했습니다.

프로젝트는 사용자가 지정한 로컬 폴더에 저장되며 설치·업데이트·제거 시 삭제되지 않습니다.

Recorder (가칭) 0.1.1 · 배포 후보

내부 설치·배포 검증을 위한 후보입니다. 공개 릴리스가 아닙니다.

  • ASIO 장치 연결 실패 수정: 벤더 ASIO 드라이버(Apartment 모델 COM)를 카메라 워커(MTA) 대신 메시지 스레드에서 생성·열기·닫기합니다. 0.1.0에서 "ASIO requires an output callback and supported buffer size"로 표시되던 문제입니다.
  • 장치 연결 실패 시 드라이버가 보고한 실제 오류 문구를 그대로 표시합니다.
  • 회귀 테스트 추가: 오디오 장치 실패는 설정 적용 시 즉시 보고됩니다.

표시명·공개 URL·정확한 대응 소스 묶음·회사 계약·지원 최소 OS는 확인 중입니다. 클린 PC 설치·업데이트, 정전 복구, 실물 웹캠 2대와 스튜디오 오디오 인터페이스 검증은 대표 실물 테스트 항목입니다. 미디어 기능의 최종 제공 범위와 성능을 이 후보 노트로 보장하지 않습니다.

Recorder (가칭) 0.1.0 · 배포 후보

내부 설치·배포 검증을 위한 후보입니다. 공개 릴리스가 아닙니다.

  • 고정 FFmpeg LGPL v3-or-later SDK의 아카이브·헤더·DLL과 전이 의존성을 검사합니다.
  • 사용자 계정별 설치기와 .recorder 프로젝트 연결을 준비했습니다.
  • 게시 없이 설치기·서명·배포 manifest·사이트 미리보기를 만드는 경로를 추가했습니다.

표시명·공개 URL·정확한 대응 소스 묶음·회사 계약·지원 최소 OS는 확인 중입니다. 병행 라운드 병합 후 종료 조건·앱 메뉴 연결과 클린 PC 설치·업데이트를 검증해야 합니다. 미디어 기능의 최종 제공 범위와 성능을 이 후보 노트로 보장하지 않습니다.
