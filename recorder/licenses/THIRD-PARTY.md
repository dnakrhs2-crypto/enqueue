# 제3자 고지 확인 목록 (배포 후보)

이 목록은 실제 SDK configure 출력의 재고이며, 전체 고지/SBOM 완료 선언이 아니다.
FFmpeg DLL 외부의 추가 DLL이 없다는 PE 검사만으로 내부 정적 의존성이 없다고 판단하지 않는다.
각 구성요소의 버전·소스·원저작권·라이선스 본문은 해당 BtbN 빌드 증거로 보충한다.
확인 전 release-gates.json의 third-party-notices/exact-corresponding-source는 UNVERIFIED로 유지한다.

| 구성요소 | 현재 근거 / 남은 확인 |
|---|---|
| FFmpeg | LGPL-3.0-or-later. SDK LICENSE.txt와 각 DLL license API 확인. LGPL/GPL 본문 동봉. |
| WinSparkle 0.9.4 | 로컬 SDK COPYING·COPYING.expat 동봉. 내부 전이 구성요소의 고지 범위는 배포 담당 확인. |
| JUCE 8.0.15 | 회사 계약의 Recorder 적용·모듈 내부 제3자 고지: **배포 담당·CEO 확인**. |
| Steinberg ASIO | 회사 보유 계약의 새 앱 적용·상표·고지: **배포 담당·CEO 확인**. 계약상 허용되지 않은 SDK 재배포 금지. |
| AVC / H.264 | 제품·지역·배포 조건의 계약: **배포 담당·CEO 확인**. |
| AAC | 제품·지역·배포 조건의 계약: **배포 담당·CEO 확인**. native AAC 선택은 계약 승인 근거가 아님. |
| GCC / MinGW / libgomp 등 | gcc 15.2.0, crosstool-NG 1.28.0.23_185f348 문자열 확인. 별도 runtime DLL 없음. 정적 코드·예외·소스·고지 미확인. |
| r8brain / 앱 내 제3자 코드 | 최종 병합 본선의 링크/모듈 목록으로 SBOM과 고지 보충: 배포 담당 확인. |

다음은 **활성화 옵션** 원문이다. 라이브러리 이름·버전·라이선스를 추정하지 않는다.
실제 링크된 소스 및 전이 라이브러리는 고정 BtbN scripts.d/patches와 빌드 로그로 대조한다.
기능 옵션(예: shared, version3)도 포함했다.
