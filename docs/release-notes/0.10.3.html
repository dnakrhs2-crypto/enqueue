Enqueue 0.10.3

  • 프리웨이트·포스트웨이트 진행 표시. GO 뒤 프리웨이트가 도는 동안 큐 리스트의 프리웨이트 칸이 남은 시간으로 카운트다운하며 파랗게 채워지고 행도 파란색이 되며, 활성 큐 패널에 "프리웨이트" 카드(남은 시간·진행 막대·× 취소)가 뜹니다. 자동 계속의 포스트웨이트(포스트웨이트 칸, 재생 중인 큐 카드의 알약)와 대기 큐(길이 칸, "대기" 카드)도 같은 방식으로 보입니다. 이제 프리웨이트를 넣은 큐가 시작됐는지 안 됐는지 바로 보입니다.
  • 설정 메뉴. "오디오" 메뉴가 "설정" 메뉴가 됐습니다: 오디오 출력 설정 · 오디오 패치 · VST3 플러그인 관리 · 마스터 버스 인서트 · 글씨·화면 크기(이 PC, 100 / 110 / 125 / 150%) · 프로젝트 설정. 프로젝트 설정은 파일 메뉴에서 여기로 옮겼고, 글씨·화면 크기는 프로젝트 설정 창 대신 이 메뉴에서 바로 고릅니다.
  • LUFS 표기. 다음 큐 칸의 평균 LUFS가 "평균 · LUFS 20초 ▾" 순서로 읽힙니다.
  • 보라색 강조 정리. 메뉴바 항목을 누르거나 지나갈 때 보라색으로 꽉 차던 강조와 표 제목줄의 보라색 강조를 슬레이트 톤(밝은 면·밑줄)으로 바꿨습니다. 프로젝트 설정 창에서 탭을 바꿔도 첫 입력칸으로 포커스가 튀지 않습니다.
  • 대기 취소가 뒤까지 정리됩니다. 대기 카드의 ×, 큐 정지, 제어 큐의 정지, 다른 큐 페이드 정지는 그 큐 뒤에 예약돼 있던 자동 계속 시작(과 그 팔로우)까지 함께 취소합니다(전에는 뒤 큐가 예정대로 시작했습니다). 재생 중 큐 카드의 ×는 소리만 페이드 정지하고 이 큐의 예약된 시작(재시작 등)은 취소하며, 뒤따르는 자동 계속은 그대로 진행합니다.
