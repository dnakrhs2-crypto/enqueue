Enqueue 0.15.0

  • 자동 레벨 맞추기 — 설정 > 자동 레벨 맞추기...에서 켜고 목표 LUFS를 정하면, 마스터로 나가는 소리를 그 값에 맞춰 천천히 조절합니다. 사람이 페이더를 만지듯 몇 초에 걸쳐 부드럽게 움직이고, 갑자기 아주 커진 곡은 1초 남짓 만에 빠르게 내립니다. 무음과 짧은 효과음에는 반응하지 않고, 길고 큰 효과음은 잠깐 내렸다가 끝나면 바로 원래대로 돌아오며, 페이드·볼륨 큐·덕킹처럼 일부러 바꾸는 소리는 건드리지 않습니다. 설정은 프로젝트에 저장되고, 켜 둔 프로젝트는 0.15.0 이상에서 열립니다.
  • 스페이스바 재생/일시정지 — 설정 메뉴에서 켜면 Space가 재생 중에는 일시정지, 일시정지 중에는 재개, 멈춰 있을 때는 GO가 됩니다. 기본은 꺼져 있고 GO 버튼과 MIDI는 그대로입니다.
  • 파형 높이가 큐 레벨을 따라갑니다 — 게인을 올리면 파형이 커지고, 내리면 작아집니다.
