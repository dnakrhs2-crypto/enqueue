Enqueue 0.14.0

  • 메인 화면 배치를 정리했습니다. 색과 글꼴은 그대로이고, 버튼과 칸의 자리만 바뀌었습니다.
  • GO 버튼이 정사각형이 됐고, 위쪽 운영 칸이 낮아져 큐 목록이 한 화면에 더 많이 보입니다(1440×900 창에서 9줄 → 12줄).
  • 일시정지와 페이드아웃은 한 기둥으로 모았고, 전체 페이드 정지는 단독으로 크게, 페이드 시간 설정(톱니)은 그 아래 따로 뒀습니다.
  • 아래 상태줄을 없앴습니다. 오디오 장치 상태는 메뉴 줄 가운데에, 큐 개수·MIDI·편집/쇼 모드 단축키 안내는 큐 목록 탭 줄 오른쪽에 있습니다.
  • 큐 인스펙터의 제목과 탭이 한 줄로 합쳐졌고, 기본 탭은 큐 / 재생 / 트리거 세 묶음으로 나뉘었습니다. 플러그인 탭의 [+ 플러그인]·[관리...]는 오른쪽 위로 옮겼습니다.
  • 파일 경로가 칸보다 길면 앞부분을 줄이고 파일 이름이 보이게 했습니다.
  • 목록과 인스펙터 사이 경계를 직접 옮겨 둔 적이 있으면 그 비율은 그대로 쓰입니다.
