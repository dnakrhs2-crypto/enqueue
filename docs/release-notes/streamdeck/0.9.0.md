## LiveMix Stream Deck 플러그인 0.9.0 (테스트판)

LiveMix 0.6.0 이상 + Stream Deck 앱 7.1 이상(Windows)에서 동작합니다. 휴대폰의 Stream Deck Mobile(무료 6키)로도 됩니다.

설치 순서
1. LiveMix 0.6.0 설치 → 설정 → **외부 제어 (Stream Deck)** → '외부 제어 사용' 켜기 (주소와 '연결 대기 중'이 표시됩니다).
2. `com.gomtwigim.livemix.streamDeckPlugin` 파일을 더블클릭 → Stream Deck 앱이 설치를 안내합니다.
3. Stream Deck 앱의 **LiveMix** 항목에서 키를 끌어다 놓고, 각 키의 설정에서 마이크·FX를 고릅니다.

키
- 마이크 ON/OFF (마이크별, 램프로 상태 표시) · 전체 마이크 · 마이크 뮤트그룹 · FX 뮤트그룹 · 플러그인 그룹(1~5) · 상태
- Stream Deck +: **FX 보내는 양** 다이얼 — 돌리면 1%/5%씩, 짧게 누르면 프리/포스트 전환

알아둘 것
- LiveMix가 꺼져 있거나 외부 제어가 꺼져 있으면 키에 '미연결' / '제어 꺼짐'이 표시됩니다.
- 세션을 바꿔 마이크가 없어지면 '채널 없음'으로 표시되고, 같은 이름이 하나뿐이면 자동으로 이어 붙습니다.
- 이 판은 테스트용(0.9.0)입니다. 아이콘은 임시이고, 마켓플레이스 등록 전 정식 1.0.0으로 바뀝니다.
