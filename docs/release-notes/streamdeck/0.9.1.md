## LiveMix Stream Deck 플러그인 0.9.1 (테스트판)

0.9.0에 더해진 것
- **FX 보내는 양 ± 키** — 다이얼이 없는 기기(휴대폰 Stream Deck Mobile, 일반 스트림덱)에서도 보내는 양을 바꿀 수 있습니다. 키 설정에서 마이크·FX를 고르고 올리기/내리기(1·5·10%)나 특정 값(0~100%)을 지정합니다. 키에 현재 %가 표시됩니다.

설치: 파일을 열면 Stream Deck 앱이 기존 플러그인을 이 판으로 바꿔 줍니다. LiveMix 0.6.0 이상 + 설정의 '외부 제어 사용' 켜기.

키 목록: 마이크 ON/OFF · 전체 마이크 · 마이크 뮤트그룹 · FX 뮤트그룹 · 플러그인 그룹 · FX 보내는 양 ± · 상태 · (스트림덱+ 다이얼) FX 보내는 양
