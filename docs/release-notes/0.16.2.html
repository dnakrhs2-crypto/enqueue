Enqueue 0.16.2

좁은 창과 125%·150% 배율에서 잘리거나 가려지던 화면을 고치고, 읽기 어려운 글자 색을 손봤습니다. 새 기능은 없습니다.

큐 목록

  • 창이 좁으면 파일 열부터 줄입니다. 그래도 모자라면 파일 열을 숨겨서 길이·포스트웨이트·진행 열이 화면 밖으로 밀려나지 않습니다. 직접 넓혀 둔 열 폭은 창을 다시 키우면 돌아오고, 파일 이름은 인스펙터에서 볼 수 있습니다.
  • 배지가 큐 이름 자리를 차지해 이름이 한두 글자만 보이던 것을 고쳤습니다. 이름이 먼저 보이고, 자리가 남을 때만 배지가 붙습니다.
  • 무한 반복 큐의 길이 칸에 ∞ 기호가 점처럼 작게 보이던 것을 키웠습니다.
  • 창을 줄이거나 배율을 바꿔도 선택한 큐가 표 아래로 숨지 않습니다.
  • 리스트가 많을 때 리스트 추가(+) 버튼이 사라지던 것을 고쳤습니다. 자리가 남으면 보고 있는 리스트 이름을 먼저 넓힙니다.
  • 행을 끌어 옮길 때 나오는 위치 숫자가 0부터 세던 것을 1부터로 고쳤습니다.

위쪽 칸

  • 오디오 장치 상태가 낱말 중간에서 두 줄로 접히고 CPU·피크 값이 사라지던 것을 고쳤습니다. 자리가 모자라면 장치 이름부터 줄입니다.
  • 좁은 창에서 다음 큐 이름과 평균 LUFS 제목이 잘리던 것을 고쳤습니다. 좁으면 두 계측을 위아래로 놓고, 아랫줄의 길이·설정 값은 다 들어갈 때만 보여 줍니다.
  • 편집 모드·쇼 모드 안내가 두 줄로 접히던 것을 고쳤습니다. 한 줄에 다 들어가지 않으면 숨깁니다.

큐 인스펙터

  • 150% 배율의 작은 창에서 생기던 가로 스크롤을 없앴습니다.
  • 꺼져 있는 시간 트리거·크로스페이드·다른 큐 정지·덕의 아래 칸이 켜진 것처럼 보이던 것을 흐리게 바꿨습니다. 값은 그대로 남습니다.
  • 쇼 모드에서 고칠 수 없는 칸이 밝게 남던 것을 흐리게 바꿨습니다.
  • 재생 탭 파형 눈금 끝의 시각 글자가 겹치던 것, 그룹 시간축의 0초가 비어 보이던 것을 고쳤습니다.
  • 레벨·트림·플러그인 탭 안내가 낱말 중간에서 끊기던 것을 고쳤습니다. 이제 띄어쓰기에서만 줄을 바꾸고, 다 못 보이면 마우스를 올려 전체 문장을 볼 수 있습니다.
  • 외부 입력(MIDI) '미지정' 글자가 칸 테두리에 붙던 것을 고쳤습니다.
  • 기본 탭에서 Tab 키가 번호, 이름, 프리웨이트 순서대로 움직입니다.

입력 실수

  • 이미 쓰는 번호나 잘못된 시간을 넣으면 그 칸에 경고색 테두리가 생깁니다.
  • 페이드 시간·시간으로 로드 창에 잘못 입력하면 창을 닫지 않고 그 자리에 오류를 보여 줍니다. 재번호 창은 빈 값이면 적용하지 않습니다.

글자 색

  • 선택 배지, 켜진 모드·요일 버튼, 진행 열 제목, 선택한 줄 위의 누락 표시, 그룹 막대 위 시간 글자를 더 잘 보이게 바꿨습니다.
  • 경고 목록과 프로젝트 열기 경고에 정보(i) 대신 경고(!) 아이콘을 씁니다.
