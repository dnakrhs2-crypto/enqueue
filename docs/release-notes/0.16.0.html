Enqueue 0.16.0

  • 자동 레벨 맞추기 — 큐 음량을 미리 재서 맞춥니다 — 자동 레벨을 켜면 올라와 있는 오디오 큐를 한 번씩 재서, 큐마다 시작부터 목표 음량으로 나오게 맞춰 둡니다. 끄면 원래 음량으로 돌아갑니다. 한 번 잰 파일은 기억해 두어 다시 열 때 기다리지 않고, 재생 중에는 분석을 천천히 해서 재생에 영향을 주지 않습니다. 진행 상황은 설정 > 자동 레벨 맞추기... 창에서 볼 수 있습니다. 3초보다 짧은 효과음과 마이크 큐는 지금처럼 재생하면서 맞춥니다.
  • 상태줄의 '읽기 끊김' — 큐 파일을 제때 읽지 못해 소리가 비었던 적이 있으면 화면 아래 상태줄에 횟수가 나옵니다.
