GoCue 0.8.2

QA 반영판: 화면 구성과 이펙트 순서.

  • 크기 조절·접기: 큐 목록과 인스펙터 사이, 큐 목록과 활성 큐 패널 사이에 구분선이 생겼습니다. 끌면 크기가 바뀌고(창 크기를 바꿔도 비율 유지), 구분선의 화살표나 더블클릭으로 접었다 폅니다. 인스펙터 접기 = Ctrl+I, 활성 큐 패널 접기 = Ctrl+L. 크기와 접힘 상태는 다음 실행에도 유지됩니다.
  • 창 크기 비율: GO 버튼이 창 너비에 따라 늘어나지 않고 늘 같은 모양입니다. 창 최소 높이 640.
  • 메뉴: 메뉴 글자 15 pt, 단축키 글자도 항목과 같은 크기로 표시.
  • 이펙트: 인서트가 "1번 · 2번 · 3번"으로 번호 순서대로 직렬 처리됨을 표시하고(1번을 거친 소리가 2번으로), 각 슬롯의 < > 버튼으로 순서를 바꿉니다(실행 취소 가능).
  • 인스펙터 "시간·루프" 탭 이름을 "재생"으로 바꿨습니다.
  • 도움말 > 사용 설명서(Ctrl+F1): 화면 구성 · 재생 키 · 큐 종류 · 리스트 편집 · 인스펙터 탭 · 출력/패치/플러그인 · 프로젝트/설정 · 단축키 표.
