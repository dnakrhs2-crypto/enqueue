GoCue 0.5.0

큐랩(QLab) 오디오 기능 이식 4단계 — 페이드 큐.

  • 페이드 큐(큐 > 페이드 큐 추가, Ctrl+7): 대상 오디오 큐의 재생 중 인스턴스를 지정 시간에 걸쳐 바꿉니다. 메인 레벨·매트릭스 각 칸·속도·VST3 파라미터. 절대(목표값) / 상대(현재값에 ±) 모드, 완료 시 대상 정지, 활성 칸(노란 점)만 적용 — 다른 칸을 다루는 페이드는 동시에 돌아갑니다.
  • 커브: S커브(기본) · 파라메트릭(강도, 대칭) · 직선 · 커스텀(점 찍기) + 오디오 도메인(슬라이더 / 데시벨 / 리니어). 이퀄파워 = 파라메트릭 0.5 + 리니어.
  • 대상에서 레벨 가져오기(Ctrl+Shift+T), 라이브 미리보기(편집하는 목표가 재생 중 대상에 바로 반영, 끄면 복원), 페이드 되돌리기(Ctrl+Shift+R, 최근 페이드 전 상태로).
  • 페이드 큐도 시퀀스(프리/포스트웨이트·자동 계속·자동 팔로우)·핫키·시계 트리거·덕 판정에 참여합니다. 표의 파일 열에 "→ 대상", 실행 중 진행바, 활성 큐 패널에 표시, 대상이 없으면 경고.
  • 속성 붙여넣기에 "페이드" 그룹(대상은 제외).
  • 프로젝트 파일 v3 그대로(큐 "type": "fade" + "fade" 객체). 이전 파일은 그대로 읽힘.
