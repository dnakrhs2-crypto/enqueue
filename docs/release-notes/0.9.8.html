Enqueue 0.9.8

  • 그룹 순차 반복 · 랜덤 반복. 그룹 탭의 모드에 "순차 반복"(차례로, 끝나면 처음부터 계속)과 "랜덤 반복"(무작위로 계속, 한 바퀴마다 다시 섞고 직전 곡이 바로 또 나오지 않음)이 생겼습니다. 배경음악 폴더를 하나 골라 GO 하면 정지할 때까지 이어집니다. 두 번째 GO는 다음 곡, 크로스페이드도 됩니다.
  • 플러그인 관리 새 창. 검색 칸(이름·제조사)으로 좁혀 보고, "사용" 체크를 끄면 그 플러그인이 모든 "+ 추가" 메뉴에서 빠집니다(이미 체인에 든 것은 그대로). "전부 사용"·"전부 해제"·"목록에서 빼기"·"VST3 스캔" 버튼. 설정은 이 PC에 저장됩니다.
  • 마스터 버스 플러그인 활성/비활성 시 소리 밀림 수정. 지연(레이턴시)이 있는 플러그인을 껐다 켤 때마다 소리가 그만큼 앞뒤로 튀던 것을 고쳤습니다. 이제 비활성 중에도 같은 지연을 유지해 타이밍이 흔들리지 않고, 전환은 5 ms 크로스페이드로 이어집니다(큐 인서트·패치 인서트도 동일). 플러그인이 지연을 바꾸면 따라갑니다.
  • 플러그인이 조금씩 뒤로 밀리던 것 수정. 저장이나 편집 기록을 남기는 순간 플러그인이 한 블록을 건너뛰면 그 뒤로 계속 그만큼 늦게 나오던 것을 고쳤습니다. 이제 건너뛴 입력을 바로 되먹여 플러그인의 시간이 항상 진행에 맞습니다.
  • 바이패스 되돌리기(Ctrl+Z)가 플러그인을 다시 만들지 않습니다. 예전에는 활성/비활성을 되돌리면 체인을 새로 만들어 딜레이·리버브 이력이 사라졌습니다.
  • 트리거 점검 수정 묶음. 비활성화한 큐의 핫키·시간 트리거가 다음 큐를 시작하던 것 / 그룹에 건 auto-follow·덕 복귀가 영영 안 끝나던 것 / 프리웨이트 중에 핫키를 다시 누르면 시작이 두 번 예약되던 것 / 2차 트리거로 정지했는데 뒤 큐가 새로 따라 시작하던 것 / 입력 칸 편집 중 F키 핫키가 발사되던 것 / Enter로 입력을 마치면 다음 클릭까지 핫키가 안 먹던 것 / "시작 시 다른 큐 페이드 정지"가 플레이리스트의 다음 곡·예약된 시작을 남기던 것 / 시작 제어 큐의 페이드 정지가 방금 시작한 그룹의 자식을 끄던 것 / 메시지 처리가 5초 넘게 밀리면 시간 트리거를 건너뛰던 것(이제 60초까지 따라잡음) / 프로젝트를 새로 열어도 이전 프로젝트의 시계 검사 시점이 남던 것 / 핫키 대소문자 중복("F5"·"f5") / M·I 키 핫키가 파형 편집 키에 밀리던 것 / 핫키 지정 중 Space가 GO 되던 것과 지정한 키를 누르고 있으면 바로 발사되던 것.
  • 유튜브 다운로드 창 주의 문구. "저작권 침해 우려가 있는 영상의 경우 다운로드 하지 말아주세요. 다운로드의 모든 책임은 사용자에게 있습니다."
