Enqueue 0.10.5

  • 푸터에 출력 진단 표시. 오디오 상태 줄에 피크(최근 약 1초 동안 앱 출력의 최고 샘플 레벨), 클립(장치를 연 뒤 앱 출력이 0 dBFS를 넘은 블록 수, 장치가 변환하기 전의 값), xrun(장치를 연 뒤 드라이버가 보고한 끊김과 시간 예산을 넘긴 콜백의 합)이 붙습니다. 클립이나 xrun이 0이 아니면 빨갛게 표시됩니다. 정수 포맷 ASIO 드라이버는 0 dBFS를 넘는 값을 그 지점에서 잘라내고 Windows Audio 공유 모드는 윈도우가 따로 처리하므로, ASIO에서만 소리가 자글거릴 때 클립이 올라가면 레벨 쪽, xrun이 올라가면 드라이버·버퍼 쪽을 먼저 봅니다. 두 숫자가 0이어도 끊김이 없다는 보장은 아닙니다.
