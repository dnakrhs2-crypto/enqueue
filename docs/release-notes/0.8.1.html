GoCue 0.8.1

0.8.0 릴리스 직후 받은 최종 코드 리뷰(오디오 스레드·마이크 큐) 반영판입니다.

  • 고침: 마이크 큐를 일시정지하면 앱이 죽던 문제.
  • 고침: 큰 오디오 버퍼(1024 샘플 이상)에서 라이브 트림/슬라이스 편집 직후 드물게 잡음이 날 수 있던 읽기선행 캐시 경합, 편집 시 오디오 콜백이 디스크 읽기를 기다리던 문제.
  • 고침: 오디오 설정에서 입력 9-10만 켠 상태에서 "입력 1-2" 마이크 큐가 엉뚱한 채널을 받던 문제 — 마이크 큐가 필요한 입력 1~N을 항상 엽니다. 입력을 열지 못하면 이전 장치 설정으로 되돌리고 알립니다.
  • 고침: 정확히 32채널 장치에서 콜백마다 메모리를 할당하던 경로, 큐 종료 시 오디오 스레드가 메시지를 보내던 경로, 페이드 중 레벨 갱신이 오디오 락 안에서 메모리를 할당하던 경로.
  • 고침: 마이크 큐가 디밴프 대상에 뜨던 것(반복이 없음), 로드된 마이크 큐를 편집하면 로드가 풀리던 것, 마이크 큐를 선택하고 페이드 큐를 추가하면 대상이 비던 것, 다른 리스트의 페이드 대상 정보(레벨 가져오기)를 못 찾던 것, 경고 수가 활성 리스트만 세던 것.
  • 마이크 입력은 1~32 범위로 제한(엔진이 여는 최대 입력 수).
