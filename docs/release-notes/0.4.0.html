GoCue 0.4.0

큐랩(QLab) 오디오 기능 이식 3단계 — 레벨 매트릭스 · 오디오 패치 · 멀티채널 · 오디션.

  • 레벨 매트릭스(인스펙터 "레벨" 탭): 파일 채널(행) × 큐 출력(열) 그리드. 드래그(Shift = 0.1 dB) · 더블클릭 = 기본값 · 숫자 입력(부호 없으면 음수, 빈칸 = 무음) · 우클릭 겡(같은 겡은 같이 움직임). 재생 중에도 즉시 반영. "트림" 탭 = 메인·출력별 고정 오프셋.
  • 오디오 패치(오디오 > 오디오 패치..., Ctrl+Shift+P): 큐 출력(기본 8개) → 장치 출력 라우팅 매트릭스, 패치 메인 레벨, 출력 이름, 스테레오 묶기, 큐 출력 인서트(라우팅 앞)와 장치 출력 인서트(라우팅 뒤). 패치 여러 개 만들고 큐마다 고르기. 장치 출력은 최대 64채널(오디오 출력 설정).
  • 멀티채널 파일: 3채널 이상 파일의 모든 채널을 읽어 매트릭스로 라우팅(최대 24채널). VST3 인서트는 아직 스테레오(앞 2채널).
  • AAC / M4A / MP4 파일 재생(Windows Media Foundation 디코더, 샘플 정확한 시크).
  • 오디션: Alt+Space = 오디션 GO, Alt+V = 오디션 미리듣기. 프로젝트 설정 > 오디오에서 방식 선택(그대로 / 출력 없음 / 대체 패치). 재생 메뉴 "항상 오디션"을 켜면 GO 버튼이 파랗게 바뀌고 모든 재생이 오디션으로. 오디션 중인 큐에 일반 GO = 실제 출력으로 재시작.
  • 프로젝트 설정 > 오디오: 레벨 상한/하한(매트릭스 슬라이더 범위).
  • 프로젝트 파일 형식 v2 그대로(큐에 levels / trim / patch / channels, 프로젝트에 patches 추가). 0.3.0 파일은 그대로 읽힘.
