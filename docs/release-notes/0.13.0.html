Enqueue 0.13.0

  • 볼륨 큐가 생겼습니다. 재생 중인 곡을 멈추지 않고 소리 크기만 바꾸는 큐입니다. 곡을 선택하고 큐 메뉴(또는 목록 우클릭)의 볼륨 큐 추가(Ctrl+Alt+7)로 만든 뒤, 페이드 탭에서 원래 볼륨 대비 dB와 시간을 정합니다([-3] [-6] [원래대로] 버튼도 있습니다). 예: 멘트 전에 -6 dB·2초, 멘트 뒤에 원래대로·3초. 내려가고 올라가는 모양은 커브 탭에서 큐마다 따로 고릅니다.
  • 기준이 곡의 원래 볼륨이라 같은 볼륨 큐를 두 번 눌러도 더 내려가지 않고, 소리가 바뀌는 도중에 다른 볼륨 큐를 누르면 그 자리에서 이어서 움직입니다. 대상 곡이 재생 중이 아니면 곡을 새로 틀지 않고 건너뜁니다(상태줄에 안내). 일시정지된 곡은 볼륨만 바뀝니다.
  • 지금 줄어 있는 곡이 보입니다. 원래 볼륨과 다르게 재생 중인 곡은 활성 큐 카드와 목록 이름 칸에 "볼륨 -6 dB"처럼 표시되고, 원래 볼륨으로 돌아오면 사라집니다. 볼륨 큐 줄의 파일 칸에는 "→ 1 음원 · -6 dB"처럼 대상과 값이 보입니다.
  • 활성 큐 [크게보기]. 활성 큐 제목 옆 [크게보기](또는 편집 > 활성 큐 크게보기)를 누르면 활성 큐가 별도 창에 하나 더 뜹니다. 다른 모니터로 옮겨 키우면 카드와 글씨가 창 크기에 맞춰 커집니다. 앤큐 창의 활성 큐는 그대로 있고, 크게보기 창은 보기 전용이라 잘못 눌러도 곡이 멈추지 않습니다. 크게보기 창이 앞에 있어도 Space·Esc·P·큐 핫키가 그대로 동작하고, 창 위치와 크기(최대화 포함)는 이 PC에 기억됩니다.
  • 다음 큐 칸에 페이드 인·페이드 아웃·볼륨 큐가 무엇을 하는지(볼륨 큐는 dB와 시간) 그대로 표시됩니다.
