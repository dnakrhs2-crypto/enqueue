Enqueue 0.9.9

  • 더블 GO 방지가 큐 핫키와 카트 클릭에도. 프로젝트 설정 > 일반의 "GO 사이 최소 시간" 아래에 "큐 핫키·카트 클릭에도 적용" 옵션이 생겼습니다(기본 켬). 켜 두면 같은 큐를 그 시간 안에 핫키나 카트로 다시 누른 것은 무시되고 GO 버튼이 빨갛게 깜빡입니다. 다른 큐는 바로 발사됩니다.
  • 덕이 나중에 시작한 큐에도. 덕 큐가 도는 동안 새로 시작하는 큐(재시작 포함)도 처음부터 낮춰서 시작합니다(덕 큐 자기 그룹의 자식은 제외). 덕 큐를 페이드로 정지하면 소리가 끝난 뒤에 덕 시간대로 복귀합니다(전에는 정지 명령 순간 0.2초로 복귀했습니다).
  • 대기 제어 큐의 2차 트리거. 대기 중에 다시 GO 하면 큐의 2차 트리거 규칙대로: 무시 / 정지(대기 취소, 뒤 진행 없음) / 재시작. 플레이리스트 그룹은 항상 "다음 곡"이라 트리거 탭에 그렇게 표시됩니다.
  • 시간 트리거. PC 시계를 뒤로 돌려도 이미 발사한 초는 다시 발사하지 않습니다(프로젝트를 다시 열면 초기화).
  • 프리웨이트 중 재시작 수정. 앞 큐를 프리웨이트 중에 다시 눌러 재시작할 때, 뒤에서 이미 돌고 있던 플레이리스트 그룹의 진행이 끊기던 것을 고쳤습니다(중복된 시작 예약만 지웁니다).
