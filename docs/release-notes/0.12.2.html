Enqueue 0.12.2

공연 중 사고로 이어질 수 있던 큐 재생·실행 취소·백업 문제들을 손봤습니다. 새 기능은 없고 안정성 수정만 들어간 판입니다.

큐 재생

  • "첫 큐 시작 후 그룹 진입"에서 다음 재생 위치가 그룹 밖으로 튀던 문제를 고쳤습니다. 이제 그룹에 들어가면 다음 GO가 그룹 안 큐로 이어집니다.
  • 플레이헤드 잠금을 푼 상태에서 큐 여러 개를 그룹으로 묶으면 다음 재생 위치가 엉뚱한 큐로 옮겨가던 문제를 고쳤습니다.
  • 일시정지한 큐를 페이드 인 큐로 재개할 때 첫 순간 소리가 잠깐 튀던 것을 없앴습니다.

실행 취소(Undo)

  • 파일을 교체한 뒤 실행 취소해도 다음 재생에서 교체 전 파일이 아니라 교체했던 파일이 나오던 문제를 고쳤습니다.
  • 재생 중 볼륨·엔벨로프를 바꿨다가 실행 취소하면 화면만 되돌아오고 실제 소리는 그대로이던 문제를 고쳤습니다.
  • 이름 바꾸기 같은 상관없는 편집을 실행 취소했을 때 페이드로 줄여둔 큐의 볼륨이 갑자기 원래대로 튀어 오르던 문제를 고쳤습니다.
  • 리스트·카트에서 큐를 지웠다가 실행 취소하면 새로 넣은 플러그인이 사라지고 설정값이 되돌아가던 문제를 고쳤습니다.

편집·백업

  • 메모 칸에 커서를 둔 채 창을 닫으면 저장 확인 없이 종료되어 방금 쓴 메모가 사라지던 문제를 고쳤습니다. 이제 종료 전에 편집한 내용을 반영하고 저장 여부를 묻습니다.
  • 백업 폴더가 없는 상태에서 처음 자동 백업할 때 음원 경로가 빠져, 나중에 프로젝트 폴더를 옮기면 음원을 못 찾던 문제를 고쳤습니다.
