Enqueue 0.10.0

  • 새 디자인 "슬레이트 카드". 화면 전체를 다시 그렸습니다. 슬레이트 톤 위에 살짝 떠 있는 카드 패널, 보라색 강조 하나, 초록 GO. GO 버튼은 글자만 크게 보입니다. 다음 큐 칸은 번호·이름·파일·길이·페이드·게인·패치를 한눈에, 일시정지·페이드아웃·전체 페이드 정지 버튼은 단축키 표시가 달린 2×2 배치입니다.
  • 큐 리스트. 큐 색 막대와 상태 알약(재생 중 · 페이드 아웃 · 일시정지 · 선택 · 다음 큐 · 누락 파일 · 비활성 · 핫키 · 시간 트리거 · 대기)이 이름 옆에 붙고, 재생 중인 행은 아래에 진행선이 흐릅니다. 시간은 고정폭 숫자로 정렬됩니다.
  • 활성 큐. 카드마다 남은 시간을 크게, 경과/전체와 진행 바를 함께 보여 줍니다. 패널 머리에 "재생 중 N (일시정지 M)".
  • 파형이 스테레오면 L/R 두 줄. 재생 탭의 파형이 채널별로 나뉘어 보입니다(우클릭 "표시 채널"로 한 채널만 볼 수도 있습니다).
  • LUFS 미터. 다음 큐 칸 오른쪽에 지금 나가는 소리의 라우드니스가 숫자로 보입니다. 실시간(400 ms)과 N초 평균 두 개, 평균 시간은 "20초"를 눌러 5 / 10 / 20 / 30 / 60초 중에 고릅니다(이 PC에 저장). 마스터 인서트와 전체 정지 게이트 뒤, 장치 출력 1-2 기준(BS.1770 K-가중, 무음 구간은 평균에서 제외)입니다.
  • 패치 편집기. 큐 출력의 체크박스가 "스테레오로 묶기"로 바뀌었고, 장치 출력 인서트 칸은 그걸 이미 쓰는 패치에서만 보입니다(큐 출력 인서트와 헷갈리지 않게). 기존 프로젝트의 장치 출력 인서트는 그대로 동작합니다.
  • 편집 모드 / 쇼 모드 전환이 메뉴바 오른쪽으로 갔습니다. 푸터에는 큐 수·경고와 오디오 장치·샘플레이트·버퍼·출력 지연이 보입니다.
