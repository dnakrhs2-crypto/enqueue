Enqueue 0.12.1

  • 닫았다가 다시 열면 최근 프로젝트를 물어봅니다. 앱을 켤 때 "최근 프로젝트 다시 열기" 창이 떠서 마지막으로 열려 있던 프로젝트를 열기 / 항상 열기 / 새 프로젝트 중에서 고릅니다. "항상 열기"를 고르면 다음부터는 묻지 않고 바로 엽니다.
  • 설정 > 시작할 때 최근 프로젝트 (이 PC)에서 묻기 / 항상 열기 / 열지 않음을 바꿀 수 있습니다. 이 설정은 이 PC에 저장됩니다.
  • 저장한 적 없는 새 프로젝트는 되살릴 파일이 없어 대상이 아니고, 파일을 더블클릭해 열었거나 업데이트 뒤 자동으로 다시 연 경우, 안전 모드(Shift)로 켠 경우에는 묻지 않습니다. 다시 열 때 프로젝트의 "프로젝트를 열 때 큐 시작"은 평소처럼 적용됩니다.
