GoCue 0.6.0

큐랩(QLab) 오디오 기능 이식 5단계 — 슬라이스 · 피치 유지 · 디밴프.

  • 슬라이스(시간·루프 탭 파형): M 키로 커서에 마커, 마커마다 재생 횟수(더블클릭: 숫자, 0 = 건너뜀, x = 무한), 드래그 이동, Delete 삭제, 우클릭 메뉴에서 전부 삭제 / 파일의 큐 마커 가져오기(WAV·AIFF). 무한 슬라이스는 디밴프(또는 2차 트리거 "이번 반복만")로 빠져나와 다음 슬라이스로 이어집니다. 재생 중 편집도 반영.
  • 피치 유지(시간·루프 탭): 속도를 바꿔도 음높이가 그대로 (Signalsmith Stretch, 0.25~4배). 다음 재생부터 적용.
  • 디밴프 큐(큐 > 디밴프 큐 추가, Ctrl+8): 실행하면 대상이 지금 도는 반복을 마치고 이어가거나(기본) 멈추고, 그 순간 다음 큐를 시작. 루프 BGM을 음악적으로 끝낼 때.
  • 프로젝트 파일 v3 그대로(큐 "type": "devamp", "audio.slices"). 이전 파일은 그대로 읽힘.
