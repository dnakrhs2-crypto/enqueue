Enqueue 0.12.0

  • MIDI로 조작할 수 있습니다. 프로젝트 설정(Ctrl+Shift+,)의 단축키·MIDI 탭 위쪽 "MIDI 입력 — 이 PC"에서 연결된 MIDI 장치를 체크하고, 명령(GO, 정지, 페이드, 큐 이동 등 단축키가 있는 모든 명령)에 MIDI 노트나 CC를 붙일 수 있습니다. 풋스위치·패드·건반·페이더 등 일반 MIDI 장치면 됩니다. 장치 선택과 명령 매핑은 이 PC에 저장됩니다.
  • 큐 하나에도 MIDI를 붙일 수 있습니다. 큐 인스펙터 기본 탭의 핫키 옆 MIDI 칸(창이 좁으면 다음 줄)에서 입력 추가로 넣습니다. 키 핫키는 그대로 두고 MIDI만 추가되며, 큐의 MIDI 트리거는 프로젝트 파일에 저장되므로 다른 PC에서 열어도 그대로입니다(실행 취소 지원).
  • 학습(캡처)이 MIDI도 잡습니다. 학습을 누르고 장치의 버튼·건반·페달을 누르면 그 입력이 후보로 잡힙니다. 노트는 바로 등록하고, CC는 페달·버튼 / 토글 / 노브·페이더 중 하나를 골라 문턱값·방향을 확인한 뒤 등록합니다. 학습 중에는 키도 MIDI도 GO·큐를 실행하지 않고, Esc는 취소입니다.
  • 노트와 CC 규칙. 노트는 누르면 실행되고 떼면(또는 velocity 0) 해제되며, 장치를 꽂거나 프로젝트를 연 뒤 첫 누름부터 바로 실행됩니다. CC는 문턱값을 넘을 때 실행되는데, 장치를 연결한 뒤 처음 받은 값은 기준값으로만 쓰고 실행하지 않습니다(노브·페이더가 튀는 것을 막기 위해서입니다 — 페달·버튼은 노트 방식이 편합니다). GO는 키와 MIDI를 섞어 눌러도 한 번만 실행되고, 전체 페이드 정지를 0.5초 안에 두 번 보내면 즉시 정지하는 규칙은 MIDI에도 같습니다.
  • 백그라운드에서도 동작. 기본으로 앱이 뒤에 있어도 MIDI 재생 명령(GO·정지·페이드 등)이 먹습니다(설정에서 끌 수 있음). 키보드 단축키는 이전처럼 앱이 활성일 때만 동작합니다. 대화상자·파일 선택 창이 열려 있는 동안은 MIDI 실행을 잠시 멈춥니다(전체 페이드 정지는 그때도 됩니다). 장치를 켜면 바로 "연결"로 표시되고, 입력이 유실됐을 때만 "준비 대기"가 됐다가 다음 메시지에 돌아옵니다.
  • 장치가 빠졌다 돌아와도 됩니다. 선택한 입력이 사라지면 매핑은 그대로 두고 "미연결"로 표시하며, 다시 꽂으면 자동으로 다시 씁니다. 모든 MIDI 입력 자동 사용을 켜면 나중에 연결한 장치도 바로 대상이 됩니다. 푸터에 MIDI 입력 상태(연결 수·미연결·과부하)가 표시됩니다.
  • 충돌·가져오기/내보내기. 같은 MIDI 입력을 두 명령에 둘 수 없고, 명령과 큐가 겹치면 명령이 우선입니다(큐 트리거는 값을 지우지 않고 비활성 표시, 충돌이 풀리면 다시 동작). 내보내기는 키와 MIDI를 함께 담고(v2), "키보드만 내보내기"로 0.11.0 형식(v1)도 만들 수 있습니다. 0.11.0 파일을 가져오면 키보드만 바뀌고 MIDI는 유지됩니다.
  • 주의: 0.12.0으로 저장한 프로젝트(버전 7)는 0.11.0 이하에서 열 수 없습니다. Program Change·relative CC·장치별 논리 이름은 이번 버전에 없습니다.
