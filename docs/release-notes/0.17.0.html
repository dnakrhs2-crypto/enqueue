Enqueue 0.17.0

휴대폰과 태블릿 등에서 앤큐를 컨트롤 할 수 있는 기능이 추가 되었습니다. 메뉴 창에서 "모바일 연동"을 클릭해서 진행해보세요! (공유기가 없으면 불가능합니다)

  • 앱 설치 없이 브라우저로 연결합니다. 메뉴 [모바일 연동 > 웹리모트 켜기]로 켜고, [QR 코드·주소 보기]의 QR을 휴대폰 카메라로 찍으세요.
  • GO, 일시정지, 페이드아웃, 전체 페이드 정지(두 번 누르면 즉시 정지), 재생 중인 큐의 일시정지·정지, 탭 바꾸기, 카트 실행을 휴대폰에서 할 수 있습니다.
  • 편집 모드에서 큐를 끌어 순서를 바꾸면 PC 큐 리스트에도 그대로 바뀝니다. 쇼 모드·편집 모드도 휴대폰에서 고를 수 있습니다.
  • PC와 휴대폰이 같은 공유기(와이파이)에 연결되어 있어야 합니다. 처음 켤 때 Windows 방화벽 창이 뜨면 [허용]을 누르세요.
