GoCue 0.8.0

큐랩(QLab) 오디오 기능 이식 3~7단계를 한 번에 담은 릴리스입니다. 프로젝트 파일은 버전 5(큐 리스트/카트)로 저장되며, 이전 버전 파일은 그대로 읽힙니다.

레벨 매트릭스 · 오디오 패치 · 멀티채널 (3단계)

  • 큐마다 레벨 매트릭스(파일 채널 × 큐 출력, 메인·입력·출력·크로스포인트 dB, 겡) + 트림 탭. 재생 중에도 즉시 반영.
  • 오디오 패치(오디오 > 오디오 패치, Ctrl+Shift+P): 큐 출력 K개 → 라우팅 → 장치 출력 M개(최대 64), 큐 출력/장치 출력별 VST3 인서트, 스테레오 묶기.
  • 멀티채널 파일(최대 24ch), AAC/M4A(Media Foundation) 재생.
  • 오디션(Alt+Space / Alt+V): 출력 없이 또는 대체 패치로 재생.

페이드 큐 (4단계)

  • 페이드 큐(Ctrl+7): 재생 중인 대상의 메인·매트릭스·속도·VST3 파라미터를 시간에 걸쳐 변경(절대/상대, 활성 칸, 완료 시 정지). S커브/파라메트릭/직선/커스텀 커브 + 오디오 도메인, 라이브 미리보기, 되돌리기(Ctrl+Shift+R).
  • 복사/잘라내기/붙여넣기, 속성 붙여넣기(Ctrl+Shift+V), 찾기(Ctrl+F), 큐 템플릿, Undo가 선택/플레이헤드도 복원.

슬라이스 · 피치 유지 · 디밴프 (5단계)

  • 슬라이스: 파형에 마커(M), 슬라이스마다 재생 횟수/건너뜀/무한, WAV 큐 마커 가져오기.
  • 피치 유지: 속도를 바꿔도 음높이 유지(0.25~4배).
  • 디밴프 큐(Ctrl+8): 루프를 이번 회차까지만 돌리고 이어가거나 멈추고, 그 순간 다음 큐 시작.

그룹 · 제어 큐 · 시퀀스 녹음 · 큐 리스트/카트 (6단계)

  • 그룹 큐(Ctrl+0, Ctrl+G 묶기): 타임라인/플레이리스트(반복·셔플·크로스페이드)/첫 큐 시작(+진입)/랜덤. 표에서 접기, 그룹 탭 타임라인 막대 편집.
  • 제어 큐(Ctrl+9): 시작·정지·일시정지·로드·리셋·이동·대기·메모·활성화·비활성화·대상 변경.
  • 시퀀스 녹음(Ctrl+Shift+E): 실제로 누른 순서와 시각을 타임라인 그룹으로.
  • 여러 큐 리스트와 카트: 표 위 탭(+). 카트는 버튼 격자 — 클릭하면 바로 재생. Ctrl+PageUp/PageDown으로 전환.

마이크 큐 (7단계)

  • 마이크 큐(Ctrl+M): 장치 입력 채널을 매트릭스·인서트·패치로 보냄. 오디오 설정에 입력 채널이 생겼고, 마이크 큐가 있으면 필요한 입력을 자동으로 엽니다.

수정

  • 코덱스 리뷰 3·4·5·6단계 반영: 오디오 스레드에서의 할당/락 경합 제거, 페이드가 대상 인스턴스에 묶임, 라이브 트림/슬라이스 편집 뒤 옛 캐시가 들리던 문제, 디밴프 경계 정확도, 탭 전환 시 Space가 입력칸에 들어가던 문제, 파일 버전/패치 id 정리 등.
