LiveMix 0.1.0

첫 공개 버전입니다. DAW 없이 ASIO 인터페이스의 마이크 입력에 VST3 플러그인을 걸어 방송에 쓰는 프로그램입니다.

  • 마이크 채널(최대 8개): ASIO 입력 하나 또는 스테레오 쌍 → VST3 체인 → 마이크 ON/OFF → 출력. 채널 이름은 더블클릭으로 바꿉니다.
  • VST3 체인: 카드에서 ①→②→③ 순서로 보이고, "체인 열기"에서 드래그로 순서 변경·켜짐/바이패스·플러그인 창 열기. 플러그인 추가 메뉴는 제조사별.
  • FX 채널(최대 4개): 채널마다 보내는 양(%)과 프리/포스트. FX 채널 패널에서 체인·돌아오는 양·출력·보내는 마이크를 봅니다.
  • 출력: 마스터 / 장치 출력 쌍으로 직접 / 둘 다. 마스터에는 자체 VST3 체인과 메인 출력 쌍.
  • 세션: 플러그인 상태까지 .livemix 파일로 저장. 변경 후 자동 저장, 다음 실행 때 마지막 세션이 열리고 오디오가 바로 시작됩니다.
  • 트레이: 최소화(또는 닫기)하면 트레이에서 계속 동작. 트레이 메뉴에서 마이크 전부 ON/OFF·열기·종료. Windows 시작 시 실행 옵션.
  • 온라인 백업: 크리에이터 이름을 넣으면 세션을 NAS(WebDAV)의 /LiveMix 백업/PC이름/크리에이터_날짜시간.livemix로 올립니다.
  • 창 폭에 따라 카드가 4열 → 2행 → 1열로 접힙니다. 미터는 채널·FX·마스터마다.
  • 업데이트는 프로그램 안에서 자동 확인(? → 업데이트 확인), 커뮤니티는 ? → 커뮤니티.
