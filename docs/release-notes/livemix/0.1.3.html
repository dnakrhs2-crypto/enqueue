LiveMix 0.1.3

  • 온라인 백업 창. 위쪽 '온라인 백업' 버튼이 창을 엽니다. 아이디와 비밀번호를 넣고 '목록 보기'를 누르면 시놀로지에 있는 백업 목록이 나오고, '지금 세션 백업'으로 올리고, 목록에서 골라 '선택한 백업 불러오기'(더블클릭도 됨)로 내려받아 그대로 세션으로 엽니다. 목록·올리기·내려받기 모두 그 아이디와 비밀번호로만 됩니다. '이 PC에 기억'을 켜면 Windows 자격 증명 관리자에 저장되고, 끄면 창을 닫을 때 지워집니다.
  • 백업은 각 계정의 홈 폴더 안 LiveMix 백업/PC이름/크리에이터_날짜시간.livemix 로 저장됩니다. 설정의 '사용자'·'비밀번호 기억' 칸은 백업 창으로 옮겼습니다.
  • 불러온 백업은 문서\LiveMix 폴더에 파일로 남습니다(같은 이름이 있으면 번호가 붙음).
  • 다른 PC에서 만든 세션의 플러그인이 이 PC에 없을 때의 안내가 한국어로 나옵니다. 그 자리는 비워 두고(소리는 그냥 통과) 저장된 설정은 세션에 그대로 남습니다.
