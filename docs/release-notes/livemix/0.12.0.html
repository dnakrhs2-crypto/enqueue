LiveMix 0.12.0

  • 플러그인 세트가 생겼습니다. 체인 서랍 아래 [플러그인 세트]에서 지금 체인을 세트 1~5에 저장해 두고, 새로 만든 마이크 채널이나 다른 체인에서 불러와 바로 고쳐 쓸 수 있습니다. 세트는 프로그램 전체가 같이 쓰는 칸이라 다른 세션을 열어도 그대로 남습니다.
  • 저장할 때 플러그인 순서와 설정값은 항상 들어가고, 마이크 채널이면 'FX 샌드값도 저장'·'플러그인 그룹도 저장'을 골라 함께 저장할 수 있습니다. 불러오면 저장해 둔 샌드값(같은 이름의 FX 채널로)과 플러그인 그룹도 같이 들어갑니다. FX·마스터 체인에는 플러그인만 들어갑니다.
  • 이미 찬 세트에 저장하거나 플러그인이 있는 체인에 불러올 때는 한 번 물어봅니다.
