LiveMix 0.21.0

  • 플러그인 화면을 핫키로 열고 닫습니다. 설정 창의 전역 핫키에 ‘플러그인 그룹 1~5 화면’이 생겼습니다. 키를 누르면 그 번호의 플러그인 그룹에 넣은 플러그인의 화면이 열리고, 그 화면을 쓰다가 다시 누르면 닫힙니다. LiveMix가 최소화되어 있거나 트레이에 있어도, 게임처럼 다른 프로그램을 쓰는 중이어도 플러그인 화면만 앞으로 나옵니다. 방송 중에 오토튠의 키·스케일을 바꿀 때 LiveMix 창을 다시 열지 않아도 됩니다.
  • 플러그인 화면이 닫기 전 자리에 다시 열립니다. 화면을 옮겨 두고 닫았다가 다시 열면 그 자리에 뜹니다(LiveMix를 끌 때까지). 여러 화면을 한꺼번에 열면 서로 조금씩 비켜서 뜹니다.
  • English. New global hotkeys ‘Plugin group 1–5 windows’ in Settings open or close the plugin windows of a plugin group, even while LiveMix is minimized or in the tray.
  • 日本語. 設定のグローバルホットキーに「プラグイングループ 1〜5 画面」を追加しました。LiveMixが最小化・トレイ状態でも、キーを押すとそのグループのプラグイン画面を開閉できます。
