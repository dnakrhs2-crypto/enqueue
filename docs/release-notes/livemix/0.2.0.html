LiveMix 0.2.0

  • 뮤트그룹 2개. 마이크 카드의 '출력' 옆 뮤트그룹 칩을 켠 마이크들이 마이크 뮤트그룹, FX 채널의 '출력' 옆 칩을 켠 FX들이 FX 뮤트그룹입니다. 설정에서 정한 핫키 하나로 그룹 전체를 뮤트/해제합니다. 최소화하거나 트레이에 있어도 동작합니다. 트레이 메뉴에서도 토글할 수 있습니다.
  • 뮤트 중에는 위쪽에 빨간 표시가 뜨고, 마이크 카드의 ON/OFF 버튼과 FX 리턴 값도 빨갛게 '뮤트'를 보여 줍니다. 해제하면 각 채널의 원래 ON/OFF·리턴 값이 그대로 돌아옵니다.
  • 전역 핫키는 다른 프로그램의 같은 키를 가로채므로 F 키나 Ctrl+Alt 조합을 권합니다. 글자·숫자 키는 Ctrl/Alt/Shift와 함께만 됩니다.
  • 세로 모드. 창을 좁게(폭 1000px 미만) 하면 위쪽 막대가 두 줄, 700px 미만이면 세 줄로 접히고, 마스터 카드는 세로로 쌓이며, 체인·FX 서랍은 창 전체 폭을 씁니다. 창 최소 폭이 720px에서 420px로 줄어 세로로 긴 창이 됩니다.
