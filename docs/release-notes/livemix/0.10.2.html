LiveMix 0.10.2

  • 마이크를 끈 동안 플러그인 그룹을 OFF로 바꾸고 마이크를 다시 켜면, 켜는 순간 꺼 둔 효과가 잠깐 섞여 소리가 튀던 문제를 고쳤습니다("OFF시 플러그인 OFF" 사용 시, 뮤트그룹 해제도 동일).
  • 시작할 때 핫키 등록에 실패하면(다른 프로그램이 같은 키를 쓰는 경우) 안내가 곧바로 사라져 모르고 방송하게 되던 문제를 고쳤습니다. 이제 알림 줄에 남아 있어 설정에서 다른 키로 바꿀 수 있습니다.
  • 그룹을 꺼둔(OFF) 상태에서 플러그인을 지웠다가 같은 프리셋으로 "뒤에 추가"하면 화면·Stream Deck에는 OFF인데 실제로는 켜져 있던 문제를 고쳤습니다.
