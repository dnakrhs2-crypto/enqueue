LiveMix 0.13.3

  • ASIO 드라이버가 여러 개 깔린 PC에서 쓰는 ASIO 장치를 고를 수 없던 문제를 고쳤습니다. 설정에서 장치 종류를 ASIO로 바꿀 때 목록 맨 앞 드라이버의 장치가 연결돼 있지 않으면 바로 윈도우 오디오로 되돌아갔는데, 이제 ASIO 장치 목록이 남아 쓰는 장치를 고를 수 있습니다. 고르기 전까지 소리는 원래 장치로 계속 나옵니다.
  • 설정에서 장치를 열지 못했을 때 세션에 저장된 장치가 바뀌지 않습니다. 전에는 그때 돌던 장치로 바뀌어, 원래 장치를 다시 연결해도 다음에 그 장치로 열리지 않을 수 있었습니다.
  • 모니터 출력 장치가 뽑혔다 다시 연결돼 "모니터 출력 멈춤"이 떠 있을 때, 설정에서 같은 출력 장치를 다시 고르면 다시 켜집니다. 전에는 같은 장치를 다시 골라도 아무 일도 일어나지 않았습니다. 상단 바에서 같은 입력 장치를 다시 골라도 됩니다.
