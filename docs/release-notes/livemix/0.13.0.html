LiveMix 0.13.0

  • 마이크 카드를 소리가 흐르는 순서로 정리했습니다: 마이크 → 입력 → VST3 체인 → 이펙터 → 출력. 색과 글꼴은 그대로이고, 버튼과 칸의 자리만 바뀌었습니다.
  • 입력 미터가 입력 선택칸 바로 아래로 왔고, 넓은 창에서 입력 이름이 잘리지 않습니다.
  • 뮤트그룹 버튼이 마이크 ON 바로 아래로 왔습니다.
  • 체인 칸은 플러그인 칩 아래에 [체인 열기]·[+ 추가], 그 아래 한 줄에 [플러그인 그룹]과 그룹 OFF 1~5를 모았습니다.
  • 마스터 카드는 그대로 아래에 있고, 위 카드와 같은 칸에 맞춰 체인 / 지연·LUFS / 메인 출력·출력 미터·OBS로 보내기로 묶었습니다.
  • 마이크 카드가 낮아져 한 화면에 더 많이 보입니다.
