  • 마이크 이름이 잘리지 않게. 마이크 카드의 이름 칸을 넓혀 ‘게스트 마이크 1’·‘게스트 마이크 2’처럼 끝만 다른 이름도 다 보입니다. 카드의 ··· 메뉴 버튼은 바로 아래 ‘뮤트그룹’ 줄 오른쪽으로 옮겼습니다.
  • 긴 FX 이름과 플러그인 이름은 두 줄로. FX 채널로 보내는 양 줄의 이름(‘보컬 리버브’ 등)과 VST3 체인 서랍의 플러그인 이름이 한 줄에 안 들어가면 두 줄로 보입니다. 설치되지 않은 플러그인 뒤의 ‘(없음)’도 보입니다.
  • 온라인 백업 창. 아래 상태 글이 두 줄까지 보이고, 목록에서 잘린 칸은 마우스를 올리면 전체가 보입니다. 파일 칸은 종류 칸과 겹치는 확장자(.livemix)를 빼고 보여 줍니다.
