LiveMix 0.8.0

  • 플러그인을 검색해서 넣습니다. 체인의 '+ 플러그인 추가' 맨 위에 '검색해서 추가...'가 생겼습니다. 창이 뜨면 바로 타이핑하면 되고, 이름·제조사·형식(VST2, VST3)을 띄어쓰기로 여러 단어 넣어 좁힐 수 있습니다(예: waves comp). ↑↓ 로 고른 뒤 Enter, 또는 더블클릭하면 체인 끝에 들어갑니다. 제조사별 메뉴도 그대로 있습니다.
  • 플러그인 그룹 핫키 5개. 설정 > 전역 핫키에 '플러그인 그룹 1'~'플러그인 그룹 5'가 생겼습니다. 누르면 그 번호의 그룹을 마이크 전체에서 한꺼번에 껐다 켭니다. 하나라도 켜져 있으면 전부 끄고, 다 꺼져 있으면 전부 켭니다. 최소화·트레이 상태에서도 동작합니다.
  • 온라인 백업에 '백업 이름'. 백업 창 아래에 이름 칸이 생겼습니다. 여기 적은 이름이 백업 파일 앞에 붙어서 목록에서 누구 세션인지 바로 보입니다(예: 리붕후_PC이름_날짜). 한 번 적으면 다음에도 그대로 뜨고, 비워두면 예전처럼 PC 이름과 날짜만 붙습니다.
  • 지연 경고를 닫으면 다시 뜨지 않습니다. '마이크 체인에 지연이 있는 플러그인이 있습니다' 안내는 지금까지 닫아도 1초 뒤에 다시 올라왔습니다. 이제 한 번 닫으면 그 PC에서는 다시 뜨지 않습니다.
  • 체인 목록에서 ≡ 표시를 없앴습니다. 번호만 남습니다. 순서는 번호를 잡고 위아래로 끌면 바뀝니다.
  • '다른 이름으로 저장'하면 그 이름으로 보입니다. 세션을 다른 파일 이름으로 저장하면 창 제목과 위쪽 이름 칸이 저장한 이름으로 바뀝니다. 지금까지는 처음 만들어진 '기본 세션'이라는 이름이 그대로 남아 있었습니다. 탐색기에서 세션 파일 이름을 바꾼 경우에도 바꾼 이름으로 열립니다.
  • 직접 지은 이름은 그대로 둡니다. '세션 > 세션 이름 바꾸기...'로 지은 이름은 다른 파일 이름으로 저장하든 파일 이름을 바꾸든 유지됩니다. 그 칸을 비우면 다시 파일 이름을 따라갑니다. 0.7.0 이전에 저장한 세션 중 파일 이름과 다른 이름이 들어 있는 것은 직접 지은 이름으로 보고 그대로 둡니다 - 바꾸려면 '세션 이름 바꾸기'를 쓰세요.
