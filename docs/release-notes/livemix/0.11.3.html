LiveMix 0.11.3

  • 플러그인에 '재생 중' 신호를 보냅니다. 설정에 재생 신호 보내기 (학습 플러그인 사용)가 생겼고 기본으로 켜져 있습니다. 켜져 있으면 모든 플러그인이 DAW에서 재생 중일 때처럼 템포 120·4/4 박자와 흘러가는 재생 위치를 받습니다. 재생 중일 때만 학습하거나 측정하는 플러그인이 LiveMix에서도 동작합니다. 템포에 맞춰 움직이는 딜레이·LFO가 전과 다르게 들리면 이 설정을 끄세요.
  • 플러그인 안에서 바꾼 설정이 저장에서 빠지지 않습니다. 학습 결과나 플러그인 자체 메뉴에서 고른 프리셋처럼 플러그인이 LiveMix에 알리지 않고 바꾼 내용도, 플러그인 창을 닫을 때·세션을 바꿀 때·백업할 때·종료할 때 확인해서 저장합니다.
