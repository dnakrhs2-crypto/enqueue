LiveMix 0.1.8

  • 글씨를 전체적으로 키웠습니다.
  • '+ 추가'를 누르면 플러그인 목록이 그 버튼 옆에 열립니다.
  • 단축키: Ctrl+S 저장, Ctrl+Shift+S 다른 이름으로 저장, Ctrl+N 새 세션. 세션 메뉴에도 표시됩니다.
  • FX 채널 탭과 이펙터 칸에서 이름이 기본값(FX 1)일 때 "FX1 FX 1"처럼 두 번 나오던 것을 한 번만 보이게 했습니다.
  • 위쪽 '?' 버튼은 '정보'로, DSP 표시는 CPU로 바꿨습니다.
  • 트레이 아이콘이 검게 나오던 문제를 고쳤습니다. 트레이에는 프로그램 아이콘(빨간 ON)이 그대로 나옵니다.
  • 제목 표시줄의 최소화 버튼으로도 트레이로 들어갑니다(설정 '최소화하면 트레이로'). 이전에는 닫기 버튼만 트레이로 갔습니다.
