LiveMix 0.17.6

  • 일부 공유기에서 방장을 할 때 다른 곳의 LiveMix 참가자가 들어오지 못하던 문제를 고쳤습니다. 공유기 자동 포트 열기(UPnP)로 포트가 열리지 않는 방장 가운데, 바깥에서 먼저 온 연결을 막는 공유기를 쓰는 경우 참가자가 '연결 중'에서 넘어가지 못했습니다. 들어오는 사람이 0.17.6 이상이면 연결됩니다.
  • 연결하지 못했을 때 '방장이 방을 닫았습니다' 대신 실제 상태를 보여 줍니다. 처음부터 연결되지 않으면 '방장 PC에 연결하지 못했습니다', 연결된 뒤 끊기면 '연결 끊김'으로 나옵니다.
