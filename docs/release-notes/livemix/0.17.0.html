LiveMix 0.17.0

  • 합방 3명까지, 웹 브라우저로도 참여. 방장 말고 두 사람까지 들어올 수 있습니다. LiveMix가 없는 사람도 합방 창의 웹 초대 QR이나 주소로 크롬·엣지에서 들어오고, 방장이 [수락]하면 연결됩니다(웹은 방에 한 명, 헤드폰 필요).
  • 사람마다 상대 음량. 합방 창의 사람 줄마다 아래 슬라이더로 따로 맞추고, 닉네임별로 기억합니다. 웹으로 들어온 사람도 자기 화면에서 사람마다 맞춥니다.
  • OBS 소스 'LiveMix 합방 상대 1'·'LiveMix 합방 상대 2'. 상대를 사람마다 따로 OBS에 넣을 수 있습니다. 이미 넣어 둔 'LiveMix 합방 상대' 소스는 그대로 1번 자리로 동작합니다.
  • 마스터 녹음. 마스터 카드의 LUFS 옆 [녹음]으로 WAV(24비트) 또는 MP3(128/256/320 kbps)로 녹음합니다. 합방 중에 시작하면 내 소리, 상대마다, 전체를 따로 파일로 남깁니다. 멈출 때는 녹음 창을 다시 열어 [녹음 중지]를 누릅니다.
  • 0.16 이하와는 지금처럼 2명 합방입니다. 웹 초대와 3명 합방은 방장과 참가자 모두 0.17.0 이상일 때 됩니다.
