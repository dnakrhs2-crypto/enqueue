LiveMix 0.7.0

  • 채널마다 팬 조절. 모노 마이크는 소리를 왼쪽·오른쪽에 배치하고, 스테레오 채널은 좌우 균형을 조절할 수 있습니다. 가운데에서는 기존과 같은 음량을 유지하며, 움직일 때는 음량이 부드럽게 바뀝니다.
  • 출력 아래 슬라이더. 채널 카드의 '출력' 아래, '입력 미터' 위에 '팬' 슬라이더가 생겼습니다. C는 가운데, L30은 왼쪽 30%, R100은 오른쪽 끝입니다. 가운데 근처에서는 가운데에 맞춰지며, 더블클릭하면 가운데로 돌아옵니다.
  • FX 샌드에는 영향 없음. 팬은 채널의 플러그인 체인과 ON/OFF를 거친 뒤 마스터·직접 출력에 똑같이 적용됩니다. FX로 보내는 프리·포스트 샌드는 팬의 영향을 받지 않습니다.
  • 세션 파일 버전 3. 팬 설정도 세션에 저장됩니다. 이전 세션은 팬이 가운데인 상태로 열립니다. 이 버전에서 저장한 세션은 예전 LiveMix로는 열리지 않으므로, 다른 PC에서도 LiveMix를 0.7.0 이상으로 업데이트하세요.
