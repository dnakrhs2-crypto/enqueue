LiveMix 0.6.0

  • Stream Deck 연동 (외부 제어). 설정에 '외부 제어 (Stream Deck)' 항목이 생겼습니다. '외부 제어 사용'을 켜면 이 PC 안에서만 통하는 제어 통로가 열리고, LiveMix Stream Deck 플러그인이 자동으로 연결됩니다. 마이크 ON/OFF, 전체 마이크, 마이크·FX 뮤트그룹, 플러그인 그룹을 키로 조작하고 Stream Deck +의 다이얼로 FX 보내는 양을 조절할 수 있습니다. 기본값은 꺼짐이며, 켜지 않으면 아무것도 달라지지 않습니다.
  • 플러그인은 따로 설치합니다. 곰튀김.com/livemix 에서 Stream Deck 플러그인 파일을 받아 설치하세요. Stream Deck 앱 7.1 이상, Windows 전용입니다. 휴대폰의 Stream Deck Mobile로도 쓸 수 있습니다.
  • 제어 로그. 외부 제어의 연결·해제 기록이 %APPDATA%\LiveMix\logs\control.log에 남습니다. 토큰이나 세션 내용은 기록하지 않습니다.
