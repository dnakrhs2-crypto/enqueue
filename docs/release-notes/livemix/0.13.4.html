LiveMix 0.13.4

  • 체인에서 플러그인의 X를 누르면 확인 창이 뜹니다. 전에는 바로 지워져 조정값까지 사라졌습니다. 마이크·FX 채널을 지울 때와 같은 창입니다.
  • 미터 양 끝 눈금(-40, 0)이 보입니다.
  • 꺼진 마이크 카드에서 다시 켜는 버튼은 흐려지지 않고 원래 밝기로 보입니다.
  • 장치에 없는 입력(예: 입력이 2개인 장치의 세 번째 마이크)이 빈칸으로 보이던 것을, 저장된 입력을 경고색으로 보여 주게 고쳤습니다. 설정값은 그대로입니다.
  • 1920×1080 모니터 150% 배율에서 창 아래 상태 줄이 작업 표시줄에 가려지던 것을 고쳤습니다.
  • 세션 이름 칸이 이름 길이에 맞춰 넓어지고, 넓은 창에서는 FX 이름도 길게 보입니다. 긴 마이크 이름은 마우스를 올리면 전부 보입니다.
  • FX 서랍 탭 글자가 작게 찌그러지던 것을 두 줄 배치로 고쳤습니다.
  • FX가 하나도 없을 때 서랍에 예전 값과 목록이 남던 것을 고쳤습니다.
  • 핫키를 받지 않은 이유가 버튼 안에 작게 나왔다 사라지던 것을, 그 줄 아래에 보통 크기로 보여 줍니다.
  • 확인 창의 큰 ? 아이콘이 제목을 덮던 것을 작은 아이콘으로 바꾸고, 문장 사이에서 줄을 바꿉니다.
  • 안내 문구를 실제 위치에 맞췄습니다: 세션 이름 말풍선(세션 메뉴), 설정의 온라인 백업 안내(온라인 백업 메뉴), 플러그인 그룹 안내(체인 열기 아래 '플러그인 그룹').
  • '샌드'로 적던 곳을 모두 '센드'로 고쳤습니다.
  • 설정의 'OFF시 플러그인 OFF'를 '꺼진 마이크는 플러그인도 멈춤'으로 바꿨습니다.
