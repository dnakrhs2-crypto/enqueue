LiveMix 0.22.0

  • Stream Deck 키로 플러그인 화면 열기·닫기. Stream Deck 플러그인 1.5.0의 새 ‘플러그인 그룹 화면’ 키를 누르면 그 번호의 플러그인 그룹에 넣은 플러그인 화면이 열리고, 그 화면을 쓰다가 다시 누르면 닫힙니다(설정의 ‘플러그인 그룹 1~5 화면’ 핫키와 같은 동작). 키 설정에서 전체 마이크 또는 마이크 하나를 고르고, 누를 때마다 열고 닫을지 열기만·닫기만 할지 정합니다. LiveMix가 최소화·트레이 상태여도, 게임처럼 다른 프로그램을 쓰는 중이어도 플러그인 화면만 앞으로 나옵니다. 플러그인 1.5.0은 곰튀김.com/livemix의 Stream Deck 절에서 받습니다.
  • English. The new ‘Plugin Group Windows’ key in Stream Deck plugin 1.5.0 opens or closes the plugin windows of a plugin group, for all mics or one mic, even while LiveMix is minimized, in the tray or behind another program.
  • 日本語. Stream Deck プラグイン 1.5.0 の新しい「Plugin Group Windows」キーで、プラグイングループのプラグイン画面を開閉できます（全マイクまたはマイク1本）。LiveMixが最小化・トレイ状態でも、他のアプリを使用中でも画面が前面に出ます。
