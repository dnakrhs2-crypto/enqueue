LiveMix 0.11.0

  • 일반 윈도우 오디오 장치를 지원합니다. ASIO뿐 아니라 USB 마이크·헤드셋·메인보드 오디오도 쓸 수 있습니다. 입력과 출력을 따로 고르거나 출력을 ‘없음 (OBS로만 보내기)’으로 둘 수 있고, 다른 장치로 모니터할 때 샘플레이트와 장치 간 속도 차이를 자동으로 보정합니다.
  • 마스터 소리를 OBS로 바로 보냅니다. 마스터 카드의 ‘OBS로 보내기’를 켜면 플러그인이 없을 때 자동으로 설치합니다. 설치 프로그램에서도 OBS 플러그인 설치가 기본으로 선택됩니다. OBS에서 ‘LiveMix 마스터’ 소스 또는 ‘LiveMix 마스터 받기’ 필터를 추가하면 가상 케이블이나 루프백 없이 소리를 받을 수 있고, 샘플레이트 차이도 자동으로 보정합니다. OBS 31.1 이상이 필요하며 설치 뒤 OBS를 다시 시작하세요.
  • 세션 파일이 버전 4로 바뀝니다. 오디오 장치와 ‘OBS로 보내기’ 설정을 함께 저장합니다. 기존 세션은 그대로 열 수 있지만, 이번 버전에서 저장한 새 세션 파일은 이전 LiveMix에서 열리지 않습니다.
