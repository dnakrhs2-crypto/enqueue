LiveMix 0.18.0

  • 위쪽 막대에 ‘마이크 뮤트’·‘FX 뮤트’ 버튼. 누르면 모든 마이크 또는 모든 FX 채널이 한꺼번에 뮤트되고, 다시 누르면 풀립니다. 뮤트그룹을 정하거나 핫키를 지정하지 않아도 됩니다. 마이크·FX마다 켜고 끈 상태와 양은 그대로라, 풀면 누르기 전 그대로 돌아옵니다. 전체 뮤트 중에는 버튼이 빨갛게 채워지고, 뮤트그룹만 뮤트 중일 때는 빨간 테두리로 보입니다.
  • 설정 > 전역 핫키에 ‘마이크 전체 뮤트’·‘FX 전체 뮤트’. 위쪽 버튼과 같은 동작을 키 하나로 합니다. LiveMix가 최소화·트레이 상태여도 됩니다.
  • Stream Deck에서도 전체 뮤트. Stream Deck 플러그인 1.4.0의 새 ‘마이크 전체 뮤트’·‘FX 전체 뮤트’ 키로 같은 동작을 하고, 전체 뮤트 중에는 마이크·FX 키가 뮤트로 보입니다. 플러그인 1.4.0은 곰튀김.com/livemix의 Stream Deck 절에서 받습니다.
  • 뮤트 중 마이크 불에 OFF 표시. 뮤트 중에 마이크 불을 눌러 끄면 불 오른쪽에 OFF가 보여, 뮤트를 풀었을 때 꺼져 있는 마이크를 미리 알 수 있습니다.
  • 화면 다듬기. 설정 창 맨 아래 ‘온라인 백업’ 안내가 잘리던 것, LUFS 막대 눈금 양 끝이 잘리던 것, 1280 폭 창에서 위쪽 막대의 비트 표시가 빠지던 것, CPU 숫자가 9%↔10%로 바뀔 때 위쪽 막대가 흔들리던 것, 버퍼 1024에서 마스터 지연 글자가 잘리던 것, 작은 화면에서 플러그인 관리 창 제목 표시줄이 화면 위로 나가던 것을 고쳤습니다. 빨간 버튼은 흰 글자가 잘 보이는 진한 빨강으로 바꿨습니다.
  • 뮤트그룹에 넣은 마이크·FX가 없을 때 뮤트그룹 핫키를 누르면 아무것도 꺼지지 않은 채 뮤트 중으로 보이던 것을 고쳐, 각 카드·FX의 ‘뮤트그룹’ 칩을 켜라고 상태줄에 알려 줍니다.
