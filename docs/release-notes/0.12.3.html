Enqueue 0.12.3

공연 중 소리 사고나 입력 유실로 이어질 수 있던 문제들을 손봤습니다. 새 기능은 없고 안정성 수정만 들어간 판입니다.

편집

  • 레벨 탭에서 숫자를 입력하고 Enter 없이 다른 큐를 누르면, 입력한 큐에는 반영되지 않고 누른 큐의 레벨이 덮여 재생 중이던 소리가 갑자기 커지던 문제를 고쳤습니다. 이제 입력은 원래 큐에 반영됩니다.
  • 메모·이름·프리웨이트·포스트웨이트를 고치고 Enter 없이 다른 큐를 누르면 입력이 사라지던 문제를 고쳤습니다.
  • 큐 번호를 고치고 Enter 없이 카트나 큐 목록에서 다른 큐를 누르면, 번호 순서로 줄이 옮겨지면서 누른 큐가 아닌 다른 큐가 재생되거나 선택될 수 있던 문제를 고쳤습니다. 이제 새 번호는 마우스를 뗀 뒤에 반영됩니다.
  • 그룹 타임라인에서 막대를 끄는 도중 다른 큐 리스트로 넘어가면 엉뚱한 큐의 시작 시각이 바뀔 수 있던 문제를 막았습니다.

재생

  • 카트에서 프리웨이트로 대기 중인 큐를 우클릭으로 정지해도 대기가 끝나면 재생되던 문제를 고쳤습니다.
  • 일시정지 제어 큐로 멈춘 그룹을 시작 제어 큐로 재개하면 이어서 나오지 않고 다음 곡으로 넘어가던 문제를 고쳤습니다.
  • 재생 중인 큐에 처음으로 플러그인을 넣으면 다시 시작하기 전까지 소리에 적용되지 않던 문제를 고쳤습니다.
  • LOAD해 둔 큐의 패치를 바꿨다가 실행 취소하면 화면은 원래 패치인데 바꿨던 출력으로 소리가 나가던 문제를 고쳤습니다.

MIDI

  • MIDI 학습 중 숫자 칸에 커서를 둔 채 다른 창으로 넘어가면 학습 상태가 풀리지 않아 그동안 MIDI 패닉이 먹지 않던 문제를 고쳤습니다.
