Enqueue 0.17.5

  • 페이드아웃이 바로 끊기던 것을 고쳤습니다. 9월 중순(0.10.4) 이전에 만든 프로젝트처럼 페이드아웃 시간이 '큐별'인 프로젝트에서는, 정지 페이드를 정하지 않은 큐에 페이드아웃(F 키, 휴대폰 '페이드아웃' 버튼)을 누르면 페이드 없이 바로 멈췄습니다. 이제 그런 큐도 2초 동안 줄어든 뒤 멈춥니다. 정지 페이드를 정한 큐는 그 시간대로 줄어듭니다.
  • 새 프로젝트의 페이드아웃 시간 기본값을 2초로 바꿨습니다. 이미 저장한 프로젝트는 저장된 시간을 그대로 씁니다.
  • 모바일 연동 화면에서 지금 상태가 보입니다. 페이드아웃 중이면 '페이드아웃' 버튼에 초록 진행바가, 전체 페이드 정지 중이면 그 버튼에 빨간 진행바가 차오르고, 일시정지 중이면 '일시정지' 버튼이 '일시정지 중'으로 바뀝니다.
