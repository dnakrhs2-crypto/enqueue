Tally (탤리) 0.1.11

프로젝트를 만들지도 않았는데 업데이트가 "녹화·더빙·내보내기·복구와 저장이 끝난 뒤 다시 시도하세요"라며 막히던 문제를 고쳤습니다.

  • 원인: 앱이 처음 켜질 때 들고 있는 빈 기본 프로젝트가 내부적으로 "저장 안 됨"으로 잡혀 있었습니다. 이제 저장할 내용(녹화한 테이크·불러온 오디오)이 실제로 있을 때만 업데이트를 막습니다. 저장된 프로젝트는 변경 사항이 있을 때만 막힙니다.
  • 막힐 때는 이유를 정확히 말합니다. 예: "업데이트 전에 먼저 끝내야 합니다: 녹화" / "프로젝트에 저장하지 않은 변경이 있습니다. 저장한 뒤 업데이트하세요." 이전처럼 모든 항목을 한꺼번에 나열하지 않습니다.
