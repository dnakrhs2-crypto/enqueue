Tally (탤리) 0.1.12

마커 기능 세 가지와 저장 단축키가 추가됐고, 녹화 버튼을 누른 뒤 녹화가 시작되기까지의 시간이 줄었으며, 내보내기 마무리 단계의 드문 튕김을 고쳤습니다.

  • 마커에 시간 표시: 마커 목록과 위치 칸이 샘플 번호 대신 시간(mm:ss.mmm, 1시간부터 h:mm:ss.mmm)을 보여 줍니다. 위치 칸에는 1:05, 01:05.500, 1:05:10 같은 시간이나 정수 샘플을 입력할 수 있고, 마커 추가 창에도 추가될 위치가 표시됩니다.
  • 마커 텍스트 내보내기: 마커 패널의 "텍스트로 내보내기"로 00:02 인트로 같은 한 줄 한 마커 텍스트 파일을 저장합니다. 시간순 정렬이고 유튜브 챕터에 그대로 붙여 넣을 수 있습니다(기본 파일 이름: 프로젝트 이름 마커.txt).
  • 색은 견본에서 고르기: #RRGGBB 코드 입력 대신 파랑·빨강·주황·노랑·초록·청록·보라·분홍·흰색·회색 열 가지 견본을 클릭(또는 키보드)해서 고릅니다. 마커 추가 창에서도 고를 수 있고, 마커 패널에서는 클릭 즉시 바뀝니다. 예전 프로젝트의 다른 색은 그대로 유지됩니다.
  • Ctrl+S로 저장: 프로젝트 저장의 기본 단축키가 Ctrl+S입니다(설정 › 단축키에서 바꿀 수 있고, 프로젝트 메뉴의 "저장" 항목에도 표시됩니다). 이전 버전에서 Ctrl+S를 다른 동작에 쓰고 있었다면 그 지정은 그대로 두고 저장은 비어 있는 다음 후보(Ctrl+Shift+S, Ctrl+Alt+S 순)를 받습니다.
  • 녹화 시작이 빨라짐: 녹화 버튼을 누른 뒤 실제 녹화가 시작되기까지의 대기(시작 여유)가 고정 0.25초에서 최소 0.10초로 줄었습니다. 디스크가 느리면 준비 중 실측한 쓰기 시간에 맞춰 늘어나고 이전의 0.25초를 넘지 않으며, 오디오 버퍼가 아주 크면 이전처럼 버퍼 두 개 길이를 유지합니다. 이 PC 실측으로 평상시 0.37초 → 0.23초(녹화 탭), 0.43초 → 0.27초(타임라인에서 들으면서 녹화)입니다. 앱을 켠 직후 첫 테이크는 ASIO 클록이 안정될 때까지 0.5초 정도 더 기다립니다. 각 테이크의 take.json에 구간별 시간(준비·대기·시작 여유)이 기록됩니다.
  • 내보내기 마무리 튕김 수정: 내보내기 결과 목록(manifest)을 쓰는 순간 이미 해제된 메모리를 읽어 드물게 프로그램이 종료될 수 있던 문제를 고쳤습니다.
  • 오류 보고: 탤리가 예기치 않게 종료되면 Windows 오류 창을 띄우지 않고 보고서(덤프)만 남긴 뒤 종료하며, 다음 실행 때 안내합니다.
