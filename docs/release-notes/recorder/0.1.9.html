Tally (탤리) 0.1.9

앱 아이콘이 바뀌었습니다. 대표가 고른 시안 1번: 차콜 바탕에 굵은 흰색 T, 오른쪽 위에 빨간 탤리 램프 한 점. 그리고 Windows 2026-09 업데이트(KB5124008) 이후 M4A/AAC 오디오를 불러오면 소리가 1024샘플(약 21 ms) 늦게 놓이던 문제를 고쳤습니다.

  • 창·작업표시줄·시작 메뉴·바탕화면 바로가기·설치 파일이 모두 새 아이콘을 씁니다. 라이브믹스의 빨간 "ON"과 더는 헷갈리지 않습니다.
  • M4A/AAC 불러오기: 업데이트된 Windows의 미디어 디코더가 AAC 앞부분(프라이밍) 프레임을 다르게 넘겨주기 시작해 오디오가 21 ms 밀렸습니다. 이제 파일의 편집 목록을 직접 읽어 어느 Windows에서든 같은 위치에 놓습니다. 업데이트된 Windows에서 0.1.8로 불러온 M4A는 다시 불러오세요.
  • 업데이트 뒤에도 작업표시줄에 옛 아이콘이 잠시 남으면 Windows 아이콘 캐시 때문입니다. 로그아웃하거나 재시작하면 새 아이콘으로 바뀝니다.
