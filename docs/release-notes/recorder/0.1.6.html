Recorder (가칭) 0.1.6

대표 수정 요청 18건을 반영했습니다. 타임라인 정리, 중간 녹화, 마커 이름, 스테레오 파형, 단축키.

  • 중간 녹화: 타임라인 화면에서는 새 테이크가 재생헤드 위치에 놓입니다. 00:05까지 녹화한 뒤 재생헤드를 00:15로 옮겨 녹화하면 그 사이는 빈 구간으로 남고, 재생과 내보내기(최종본·소재)에서는 검은 화면과 무음으로 나옵니다. 기존 클립 위에 녹화하면 겹치는 부분을 덮어쓰고(실행취소 한 번으로 복원), 녹화 화면에서는 예전처럼 타임라인 끝에 붙습니다. 재생헤드는 타임라인 끝 너머로도 옮길 수 있습니다.
  • 들으면서 녹화: 타임라인 화면에서 녹화를 시작하면 재생헤드부터 타임라인의 오디오(불러온 오디오·이전 마이크, 음소거/솔로 반영)가 들리면서 녹화됩니다. 오디오가 끝나도 녹화는 계속되고 정지하면 같이 멈춥니다. 녹음된 소리와 영상은 장치가 보고하는 입출력 지연을 빼서 들은 시각에 맞춥니다.
  • 타임라인 미리보기 제거: 위 캠 화면이 이미 있으므로 클립 안 썸네일과 재생헤드 드래그 시 뜨던 미리보기 상자를 없앴습니다.
  • 기능 정리: 구간 삭제하고 당기기, 앞으로/뒤로, 링크 해제, 선택 클립 링크, 일시정지(정지와 같음), 방금 테이크 재생, 일반/더빙 버튼, 트랙 헤더의 대상 버튼을 뺐습니다. 캠과 마이크 클립이 함께 움직이는 기본 동작은 그대로입니다.
  • 마커: 마커를 찍으면 이름 입력 창이 뜨고 Enter(확인)로 바로 들어갑니다. 누른 순간의 시각이 고정되어 창을 늦게 닫아도 밀리지 않습니다. 마커는 트랙을 관통하는 선과 색 깃발로 훨씬 잘 보입니다.
  • 파형: 스테레오 입력과 스테레오 불러온 오디오는 L/R 두 줄로 보입니다. 트랜스포트의 "파형 −/+"로 파형 세로 크기를 ×1~×16 조절합니다.
  • 음소거는 빨강, 솔로는 노랑으로 켜짐 상태가 보입니다.
  • 안 쓰는 트랙 숨김: 클립이 있거나 지금 녹화 대상(캠 사용 켜짐, 녹음 켜진 마이크)인 트랙만 보입니다. 캠2를 끄거나 마이크를 안 쓰면 그 줄이 사라집니다.
  • 드래그로 잘라내기: 클립 아래쪽(영상·파형 영역)을 드래그하면 그 구간이 모든 트랙에서 선택되고 Delete(또는 삭제 버튼)로 잘려 나갑니다(자리는 비워둠). 클립 위쪽 제목 띠를 끌면 지금처럼 이동, 가장자리는 트림, 한 번 클릭은 선택입니다.
  • 단축키: 녹화 정지 기본 키가 Space입니다(녹화 중이면 정지, 아니면 재생/정지). 저장된 옛 기본값 F10은 자동으로 Space로 바뀝니다.
  • 시작 화면: 프로젝트가 없으면 새 프로젝트 창이 먼저 뜹니다(기존 프로젝트 열기 버튼 포함).
  • 카메라 입력 모드 목록은 1080p 30fps·60fps만 보여줍니다(15·20·24fps 등 제외).
  • 글자 깨짐 수정: 창 제목의 "(가칭)", 확대 옆 축소 버튼, 오디오 불러오기 안내, 오류 문구가 제대로 보입니다.
