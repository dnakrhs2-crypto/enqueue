Tally (탤리) 0.1.15

  • 영어로 나오던 오류·안내 문구를 한국어로 바꿨습니다. 내보내기 범위 오류나 내보낼 소재가 없을 때의 안내 등이 이제 한국어로 나옵니다.
  • 저장하지 않은 변경이 있을 때 '저장 중' 대신 '저장 안 됨'으로 나옵니다.
  • 소재 뽑기 설명을 실제와 맞췄습니다. 마이크는 입력 그대로(스테레오 마이크는 스테레오 파일 1개), 불러온 스테레오 오디오는 왼쪽·오른쪽 2개 파일로 나갑니다.
  • 카메라 표시에 fps 단위를 붙였습니다(예: 캠1 · 1080p 30 fps 입력 / 프로젝트 30 fps).
  • 1366×768 화면이나 1920×1080 150% 배율에서 첫 실행 때 창이 화면 밖으로 나가던 것, 내보내기 창 제목줄이 화면 위로 올라가던 것을 고쳤습니다.
  • 타임라인 탭의 카메라 미리보기 칸을 줄여 트랙을 편집할 공간이 넓어졌습니다.
  • 좁은 창에서 편집 도구 줄의 구간 칸과 마커 추가가 잘리던 것을 고쳤습니다.
  • 마커 이름표가 시간 글자를 덮던 것을 고쳤습니다. 눈금은 위에 고정되어 아래로 스크롤해도 보입니다.
  • 확대하면 눈금이 모두 같은 시각으로 보이던 것과 1시간이 넘으면 시간이 빠지던 것을 고쳤습니다.
  • 불러온 오디오 클립 이름이 비어 보이던 것을 파일 이름으로 보여 줍니다.
  • 정상으로 열었는데 '저장된 자료를 복구했습니다'가 뜨던 것을 실제로 복구했을 때만 뜨게 고쳤습니다. 성공·안내 알림은 빨간색으로 나오지 않습니다.
  • 오디오 장치가 연결되지 않았을 때도 저장된 마이크 입력 번호를 그대로 보여 줍니다. 카메라 탭에 늘 떠 있던 '같은 카메라를 두 번 선택할 수 없습니다'를 없앴습니다.
  • 구간·마커 입력 오류가 입력칸 바로 아래에 빨간 테두리와 함께 나옵니다.
  • 내보내기에서 '전체'를 골랐는데 선택 클립 범위가 남던 것, 카메라 영상이 없는데 카메라를 고르라던 것을 고쳤습니다.
  • 설정을 연 직후에도 Tab 키로 이동할 수 있고, 버튼·체크박스·탭에 키보드 초점 테두리가 보입니다.
  • 켜진 버튼의 흰 글자와 스크롤 막대가 더 잘 보입니다.
  • 앱 정보 창의 큰 i 아이콘이 글자를 덮던 것, 새 프로젝트 창에 이미 프로젝트가 있는 폴더가 미리 채워지던 것을 고쳤습니다.
