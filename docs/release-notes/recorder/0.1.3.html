Recorder (가칭) 0.1.3

0.1.2 자동 업데이트로 받는 첫 버전입니다.

  • 샘플레이트: 아직 녹음이 없는 프로젝트는 오디오 장치의 샘플레이트를 그대로 따라갑니다. 첫 녹음 뒤에 장치 속도가 달라지면 프로젝트·장치 숫자를 함께 보여주고 어디서 바꾸는지 안내합니다.
  • 카메라 입력 모드: "MJPEG 1920x1080 5/1" 같은 표기를 "1080p 30fps · MJPEG"로 바꾸고, 카메라를 고르면 프로젝트 fps에 맞는 모드를 자동으로 선택합니다. 5fps 같은 저속 모드가 저장돼 있으면 설정을 열 때 바꿔 줍니다.
  • 타임라인 우클릭 메뉴가 마우스 위치에서 열립니다.
  • 비정상 종료 시 설정 폴더의 crash 폴더에 덤프와 보고 파일을 남기고, 다음 실행에서 파일 위치를 알려줍니다.
