Tally (탤리) 0.1.10

트랙을 손으로 숨기고 다시 보이게 할 수 있습니다.

  • 타임라인 트랙 이름 위에서 오른쪽 클릭 → 트랙 숨기기. 숨긴 트랙은 클립이 있어도, 음소거·솔로가 켜져 있어도 화면에서 사라집니다. 녹화·재생·내보내기에는 영향이 없습니다(숨겨도 그대로 녹음되고 소리도 납니다).
  • 다시 보이게 하려면 편집 메뉴 → 숨긴 트랙 N개에서 트랙 이름을 고르거나 모두 보이기. 숨긴 트랙이 있으면 타임라인 아래 안내 줄에도 개수가 표시됩니다.
  • 숨김 상태는 프로젝트에 저장되고, 실행취소(Ctrl+Z)로 되돌릴 수 있습니다. 녹화 중에는 음소거·솔로처럼 바꿀 수 없습니다.
  • 오디오를 불러오면 그 트랙은 숨겨져 있어도 자동으로 다시 보입니다.
