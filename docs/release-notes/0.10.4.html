Enqueue 0.10.4

  • 페이드아웃(F) 시간 설정. F(페이드아웃 버튼)로 큐를 끌 때 몇 초에 걸쳐 페이드할지 프로젝트 설정으로 정합니다. 전체 페이드 정지 옆 톱니바퀴를 누르면 "전체 페이드 정지 (Esc)"와 "페이드아웃 (F)" 메뉴가 각각 나오고, 0.5 / 1 / 2 / 3 / 5 / 10초 중 고르거나 직접 입력합니다. 페이드아웃은 "큐마다 정한 정지 페이드 사용"(예전 동작)도 고를 수 있습니다. 새 프로젝트는 1초로 시작하고, 이전 버전으로 만든 프로젝트는 값을 정하기 전까지 예전처럼 큐마다 정한 정지 페이드를 씁니다. 프로젝트 설정 > 일반에도 같은 칸이 있고, 페이드아웃 버튼에 지금 값이 표시됩니다.
