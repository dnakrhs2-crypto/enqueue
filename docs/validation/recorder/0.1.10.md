# Tally 0.1.10 검증 기록 (2026-09-13) — 트랙 수동 숨기기/보이기

범위: 대표 요청 "수동으로 트랙 보이고 숨기는 기능 추가해". 기존 자동 숨김(클립·녹화 대상·솔로/음소거 없는 트랙은 행 없음, 0.1.6)에 사용자가 직접 숨기고 되살리는 기능을 얹었다. 기능 커밋 68aeb2b(코덱스 write 세션 `tools/claude_harness/brief_recorder_hide_tracks.txt`, 22분) + 내 검토 수정 2건(모두 보이기 = 저널 편집 1건, 직렬화 배열 포인터 가드) + 리뷰 메모 반영 1건(숨긴 트랙이 솔로/음소거면 메뉴 이름 옆에 표시).

## 동작
- 트랙 헤더 우클릭 → "트랙 숨기기". placeholder(표시 전용) 행·녹화 잠금 중에는 없음/비활성. 스냅샷 비교로 메뉴가 뜬 사이 문서가 바뀌면 거부.
- 편집 메뉴 → "숨긴 트랙 N개" 서브메뉴(이름별 보이기, "모두 보이기" = 편집 1건 = Ctrl+Z 1회) 또는 비활성 "숨긴 트랙 없음". 하단 안내 줄/툴팁에 "숨긴 트랙 N개는 편집 메뉴에서 보이기".
- `Track::hidden`은 표시 전용: 녹화·재생·믹스·내보내기는 그대로(솔로/음소거도 유지 → 서브메뉴에 " · 솔로 켜짐"/" · 음소거" 표시). 저널·undo/redo 대상, 녹화 중 변경 불가(음소거/솔로와 동일). 직렬화는 true일 때만 기록 → 기존 체크포인트/저널 해시 유지, 옛 프로젝트는 전부 보임.
- 숨긴 트랙은 클립·녹화 대상·솔로/음소거가 있어도 행 없음; 녹화 중 마이크 placeholder도 되살아나지 않음. 오디오 불러오기가 도착한 트랙은 자동으로 보임(`revealTrack`).

## 리뷰
- 코덱스 읽기 전용 리뷰(`brief_recorder_hide_review.txt`, `hide-review1-OUT.md`): "ship" — 직렬화·체크섬·저널 정합, `onlyTrackVisibilityChanged`(undo/redo가 표시만 바꾸면 재생 재시작 없음) 보수적 판별, revealTrack 참조 수명·잠금, 헤더 이벤트·비동기 콜백 수명, 메뉴 ID(기존 최대 14 vs 1000+), UTF-8 모두 확인. 비차단 메모: 숨긴 솔로 트랙은 다른 트랙이 안 들리는 이유를 알기 어렵다 → 서브메뉴 이름 옆 " · 솔로 켜짐" 추가. 참고: 현재 불러오기는 항상 새 트랙을 만들므로 revealTrack의 숨김 해제 분기는 미래용.
