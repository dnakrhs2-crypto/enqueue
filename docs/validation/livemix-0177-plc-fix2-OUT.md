**LiveMix 0.17.7 PLC FIX2: 복구 후 재손실의 강제 무음 제거 (2026-10-29)**

FIX1의 연속 원음 30ms 조건과 정상 재생 시간의 감쇠 누적을 제거했다. 복구 겹침이 끝나면 손실 구간이 닫힌다. 다음 손실은 가장 최근의 연속된 실제 입력만 사용한다. 복구 도중 다시 손실될 때만 기존 `frozen`과 합성 경과 시간을 유지한다.

브랜치 `livemix-0177-plc`, HEAD `dae954ba228849d0824474c0e5a6f8e74096a68a`. 커밋하지 않았다. `plc_fix1_soak_done.flag`는 12:37:06 KST에 생성됐고 첫 확인(12:37:16) 때 존재했다. 모든 빌드·시험은 그 뒤 `rb.py`를 통해 roomc에서 실행했다. 이번 첫 전후 재현 실행은 12:43:58에 시작했다.

**짧은 원음 기록과 감쇠 종료 이음**

실제 연속 기록 길이를 N, 최소 주기를 Pmin(2.5ms), 최대 주기를 Pmax(15ms)라 하면 최대 탐색 지연은 `min(Pmax, N-Pmin, floor((N-1)/1.25))`다. 비교 구간은 `min(15ms, N-최대 탐색 지연)`이다. 최소 2.5ms 비교 구간과 루프의 1/4주기 이음이 실제 기록 안에 들어가는 주기만 허용한다. 이 범위가 없거나 상관이 낮으면 현재 실제 끝값을 2.5ms 페이드한다. 구멍 이전 기록이나 0으로 채운 미사용 앞부분을 피치 탐색에 섞지 않는다.

거친 상관 최고값과 0.02 이내인 국소 봉우리를 정밀화하고, 정밀 상관이 0.002 이내면 더 짧은 주기를 유지한다. 최종 상관 문턱 0.7과 최소 RMS 0.0001은 그대로다. 거친 격자에서 봉우리까지 오르는 중간값을 후보로 고르던 방식은 주기의 두 배를 선택해 복구를 불필요하게 길게 만드는 경우가 있었다.

감쇠는 첫 10ms 100%, 이후 10ms당 원래 크기의 20% 선형 감소, 합성 60ms부터 옛 파형은 0이다. 정상 출력 시간은 이 예산을 쓰지 않는다. 복구가 계속 중단돼 예산이 끝나더라도, 직전에 실제 입력이 들렸다면 그 **실제 성분만** 최대 1/4주기(최대 3.75ms)로 짧게 페이드한다. 옛 합성 성분의 보정은 60ms 기한에서 끝나며 원음 기록으로 되돌아가지 않는다. 실제 입력이 무음이면 이 실제 성분도 0이므로 FIX1의 잔류 음성이 돌아오지 않는다.

**제품 C++ 전후 재현 수치**

137Hz 순음(peak 0.4)과 137Hz의 1·2·3·5배음(진폭 0.27/0.12/0.08/0.04), R=0.63L을 사용했다. 100ms 실제 입력 뒤 손실/정상 패턴을 1초 반복한다. 계속 발성은 신호가 이어지고, 발성 중단은 실제 입력이 무음이다. 44.1kHz의 각 길이는 가장 가까운 프레임으로 반올림한다. 아래 수치는 L채널 정규화 PCM이며 스테레오 비율도 따로 검사한다.

핵심 재현인 **배음 2.5ms 손실/27.5ms 정상**:

| 장치율 | 통째로 무음인 손실 전 → 후 | 최대 인접 샘플 변화 전 → 후 | 같은 위상·길이의 단독 손실 | 수정 후 최소 손실 RMS / 원신호 RMS |
|---|---:|---:|---:|---:|
| 44.1kHz | 32/34 → 0/34 | 0.377426922 → 0.018419422 | 0.018419422 | 0.999872864 |
| 48kHz | 32/34 → 0/34 | 0.377687216 → 0.016923215 | 0.016923215 | 0.999730850 |
| 96kHz | 32/34 → 0/34 | 0.379120260 → 0.008462358 | 0.008462358 | 0.999942185 |
| 192kHz | 32/34 → 0/34 | 0.379811227 → 0.004231274 | 0.004231274 | 0.999981741 |

48kHz 순음의 같은 반복은 무음 손실 32/34 → 0/34, 최대 변화량 0.399875760 → 0.007173207이었다. 단독 손실도 0.007173207이고 수정 후 최소 손실 RMS 비율은 0.999955787이다.

48kHz 배음의 요청 변형:

| 손실/정상(ms) | 통째로 무음인 손실 전 → 후 | 최대 인접 샘플 변화 전 → 후 |
|---|---:|---:|
| 2.5/5 | 126/134 → 0/134 | 0.297315180 → 0.016917706 |
| 2.5/10 | 75/80 → 0/80 | 0.389813453 → 0.016923945 |
| 5/20 | 37/40 → 0/40 | 0.389813453 → 0.016923215 |
| 2.5/29.9 | 29/31 → 0/31 | 0.384193003 → 0.016923215 |
| 2.5/30.1 | 0/31 → 0/31 | 0.016923215 → 0.016923215 |
| 10/20 | 32/34 → 0/34 | 0.377687216 → 0.016923212 |

`2.5/5`에서는 137Hz의 약 7.3ms 복구가 계속 중단된다. 따라서 같은 손실 구간의 감쇠를 계속하고, 60ms 뒤에는 방금 들린 실제 끝값을 짧게 페이드한다. 이 경우 손실 전체를 원래 음량의 주기 반복으로 메운다고 주장하지 않는다(48kHz 배음의 최소 손실 RMS 비율 0.002042434). 강제 절단을 없애면서 옛 음성을 되살리지 않는 경로다. 복구가 끝나는 나머지 6개 패턴은 매번 새 실제 원음으로 다시 숨긴다.

네 장치율 × 순음/배음 × 계속 발성/중단 × 7개 패턴 = 112개 조합을 검사했다. 계속 발성 56개 조합의 총 3,074개 손실에서 통째로 무음인 손실은 **2,650 → 0**이었다. 발성 중단 56개 조합은 전후 모두 첫 손실 60ms 이후 최대 절댓값과 900~1,000ms RMS가 정확히 0이었다. 변화량 검사는 각 손실 위치에 같은 위상·길이의 단독 손실을 만들어 비교하며 허용치는 `단독 최대 변화량 × 1.35 + 0.001`이다.

추가로 이전 400Hz 음성이 복구된 뒤 새 137Hz 배음의 실제 기록을 5/10ms만 받은 경우를 네 장치율에서 검사했다. 다음 숨김 출력이 그 새 기록만 받은 PLC와 스테레오 샘플 단위로 같았다. 5ms 기록은 현재 끝값에서 2.5ms 페이드, 10ms 기록은 지원 가능한 주기를 찾아 이어 갔다.

전후 동일 464개 검사에서 **FIX1 기준본 316 통과·148 실패 → FIX2 464 통과·0 실패**였다. 기준본은 독립 수치 모델이 아니라 `tests/reference/plcBeforeFix2`의 실제 C++이다.

**기존 동작과 CPU**

- FIX1 재현 38개 통과. 8개 반복 무음 입력 조합의 60ms 이후 출력과 늦은 RMS는 0, 고정 파형·위상·감쇠 비교 오차도 0. 기존 기대값을 바꾸지 않았다.
