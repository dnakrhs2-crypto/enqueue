## A. 파형·시간 (큐랩 Time & Loops 탭)

1. ★ **파형 표시** — 인스펙터에 큐 파형(전체 채널 합 또는 채널 하나 선택), 줌 인/아웃(버튼·Alt+스크롤). GoCue: 없음. 작업량 중. 2·3·5의 바탕.
2. ★ **시작/끝 시간 트리밍** — 파형 위 회색 삼각 핸들을 드래그하거나 숫자 입력, 파형 클릭 후 Shift+I(시작)/Shift+O(끝). 재생 중에 바꿔도 즉시 반영. GoCue: 없음(파일 전체 재생). 중. 의존 1.
3. ★ **통합 페이드 엔벨로프** — 파형 위 노란 선을 클릭·드래그해 컨트롤 포인트로 페이드 인/아웃 모양을 그림. 곡선(부드럽게)/직선 선택, "시작/끝에 잠금"(트리밍하면 곡선이 따라 늘어남), 화살표 키로 포인트 미세 이동. GoCue: ms 숫자 + 선형 램프만. 중~대. 의존 1.
4. **재생 횟수·무한 루프** — 횟수 입력 또는 무한 루프. GoCue: 없음. 소.
5. **슬라이스(구간 마커)** — 파형에서 M키로 마커 추가, 구간별 반복 횟수(0=건너뜀, 글자=무한), 마커 최소 간격 0.05초, WAV/AIFF에 든 마커 자동 가져오기. GoCue: 없음. 대. 의존 1.
6. **재생 속도 + 피치 유지** — 0.03~33배, "피치 유지" 체크(타임스트레치). GoCue: 없음. 속도만 중 / 피치 유지 대(별도 라이브러리 필요).
7. **미리듣기(V)·리셋 버튼** — 플레이헤드 안 움직이고 선택 큐 재생(프리웨이트·자동진행 무시), 재생 중엔 일시정지 버튼으로 바뀜. 리셋 = 정지 + 임시 변경 초기화. GoCue: 없음. 소.
8. **파형 우클릭 메뉴** — 외부 편집기로 열기, 탐색기에서 보기, 표시 채널 선택. GoCue: 없음. 소.

## B. 레벨·라우팅 (Levels·Trim·출력 패치)

9. **매트릭스 믹서** — 행=파일 채널, 열=큐 출력. 메인 레벨·입력별·출력별·크로스포인트를 dB로. 빈칸=-inf, 드래그는 0dB까지·숫자 입력은 상한까지, 재생 중 즉시 반영. GoCue: 큐 게인 하나. 대.
10. **겡(Gang)** — 여러 레벨 칸을 색으로 묶어 같이 움직임(끝에 닿으면 멈춤). 중. 의존 9.
11. **입력 이름·기본 레벨로·전부 무음 버튼** — 소. 의존 9.
12. **트림 탭** — 페이더 뒤 고정 오프셋(메인·출력별). 페이드 큐·외부 제어로 못 건드리는 안전 손잡이. 소. 의존 9.
13. **오디오 출력 패치 편집기** — 패치 이름, 큐 출력 개수 1~128, 장치 선택, 큐 출력 이름(두 줄), 큐 출력→장치 출력 라우팅 매트릭스 + 패치 메인 레벨, 다른 패치에서 복사/기본값. GoCue: 장치 첫 스테레오 페어 고정. 대.
14. **큐 출력·장치 출력 이펙트 인서트** — 매트릭스로 보내는 센드/리턴식 AUX 리버브 가능. GoCue: 큐 체인 + 마스터 체인만. 중. 의존 13.
15. **레벨 상한/하한 설정** — 최대 -30dB~무제한(기본 +12dB), 최소 -180~-40dB(기본 -60dB). 소.
16. **멀티채널·추가 포맷** — 24채널까지 인식(매트릭스로 배분), CAF/AAC/M4A/MP4·동영상 파일의 오디오. GoCue: 앞 2채널만, wav/aiff/flac/mp3/ogg. 중(AAC/M4A는 윈도 Media Foundation 디코더로 가능할 것으로 보이나 확인 필요).
17. **마이크 큐** — 라이브 입력 채널을 매트릭스로 라우팅. GoCue: 없음. 대. 큐 플레이어 범위 밖이라 보류 추천.

## C. 페이드 큐 (별도 큐가 다른 큐를 페이드)

18. **페이드 큐** — 대상 큐(또는 출력 패치)의 레벨을 지정 시간(기본 5초)에 걸쳐 바꿈. 활성 칸(노랑)만 적용, 서로 다른 칸을 건드리는 페이드는 동시 실행 가능. GoCue: 큐 자체 페이드 인/아웃뿐. 대.
19. **절대/상대 모드** — 상대는 현재값에 ±(아이콘 바뀜). 소. 의존 18.
20. **페이드 곡선** — S커브(기본)·커스텀(포인트, 좌우 대칭 잠금)·파라메트릭(강도값)·직선 + 오디오 도메인(슬라이더/데시벨/리니어), 이퀄파워·이퀄게인 조합. 중. 의존 18. 3번 페이드 인/아웃에도 같은 곡선 선택지를 재사용 가능.
21. **완료 시 대상 정지** 체크 — 소. 의존 18.
22. **재생 속도 페이드** — 중. 의존 6·18.
23. **이펙트 파라미터 페이드** — 대상 큐 VST 파라미터를 페이드 큐 값으로 스무스하게(큐 출력/장치 출력 FX는 불가). 대. 의존 18.
24. **라이브 페이드 미리보기·페이드 되돌리기** — 편집 중 재생 중인 대상에 실시간 반영, 페이드 전 상태로 복원. 중. 의존 18.
25. **대상에서 레벨 가져오기** — 소. 의존 18.

## D. 큐 기본 속성 (Basics 탭)

26. **큐 번호** — 자유 텍스트(글자·기호 가능, 유일), 새 큐 자동 증가, 선택 큐 일괄 재번호(시작·증가·접두·접미), 번호 삭제. GoCue: 행 순서 자동. 중.
27. **프리웨이트/포스트웨이트** — GO 후 대기 시간 / 다음 큐로 넘어가기 전 대기. 없음. 중.
28. **진행 모드** — 계속 안 함 / 자동 계속(포스트웨이트 뒤 다음 큐 시작, 기본 동시) / 자동 팔로우(끝나면 다음 큐). 이것으로 GO 한 번에 여러 큐 = 큐 시퀀스. 없음. 중. 의존 27.
29. **메모** — 스탠바이 큐 메모가 GO 버튼 밑에 표시(서식·이미지 가능). 없음. 소.
30. **색상** — 20색 + 한 번 재생 후 바뀌는 두 번째 색. 없음. 소.
31. **플래그·아밍** — 검토용 깃발, 비활성(빗금 표시)·비활성이면 건너뛰기. 없음. 소.
32. **큐 목록 열 바로 편집** — 번호 N·이름 Q·메모 O·대상 T·프리웨이트 E·길이 D·포스트웨이트 W·진행 C 키로 즉시 편집. GoCue: 이름만. 소.

## E. 트리거·2차 트리거 (Triggers 탭·설정)

33. ★ **2차 트리거 동작** — 재생 중인 큐에 다시 GO가 오면: 무시(기본) / 패닉 / 정지 / 하드 정지 / 하드 정지 후 재시작 / 디밴프. 큐별 설정 + "키 뗄 때 2차 트리거" 옵션. GoCue: 무조건 재시작. 소.
34. ★ **더블 GO 방지** — GO 사이 최소 시간(초, 기본 0) 동안 GO 무시(버튼 빨간 테두리, 눌리면 깜빡) + "키를 뗀 뒤에만 다시 GO" 옵션. 마우스·스페이스·MIDI/OSC 모두 적용. 없음. 소.
35. **핫키 트리거** — 큐별 단축키(Esc·화살표·수정키 단독 제외). 없음. 소.
36. **시작 시 다른 큐 페이드&정지** — 같은 계층/같은 리스트/전체를 지정 시간 페이드 후 정지. 없음. 중.
37. **덕/부스트** — 재생 중 리스트의 다른 큐를 dB만큼 낮추거나 올림(페이드 시간). 없음. 중.
38. **MIDI·벽시계·타임코드 트리거** — 오디오 아님. MIDI 중 / 벽시계 소 / 타임코드(LTC·MTC) 대.

## F. 재생 제어·워크스페이스

39. **패닉** — Esc 한 번 = 패닉 시간 동안 전체 페이드아웃 후 정지, 두 번 = 하드 정지(고정). 사이드바 패닉 버튼. GoCue: Esc=즉시 전체 정지, Shift+F=전체 페이드. 소(동작 통일).
40. **선택 큐 패닉·하드 정지** — S 한 번 = 페이드 정지, 두 번 = 즉시. GoCue: S 즉시 / F 페이드. 소.
41. **일시정지/재개** — 선택 P, 전체 [ ]. 없음. 중.
42. **로드·시간으로 로드** — L로 미리 로드, Ctrl+T로 특정 시각부터 시작(음수 = 끝에서 n초 전). 없음. 중.
43. **활성 큐 패널** — 재생 중 큐 목록: 일시정지 버튼, 경과/남은 시간, 진행바(재생 초록·일시정지 노랑), 패닉 버튼, 드래그 스크럽, 정렬 방향. GoCue: 표 행 색 + 진행바 + 남은 시간. 중.
44. **리셋** — 전체 하드 정지 + 임시 변경 초기화 + 플레이헤드 맨 위. 없음. 소.
45. **편집/쇼 모드** — 쇼 모드는 인스펙터·추가/삭제/이동·붙여넣기 잠금(Esc·저장·종료는 됨). 없음. 소.
46. **플레이헤드와 선택 분리** — 스탠바이 큐(플레이헤드)와 선택 행이 따로 움직임, "플레이헤드를 선택에 잠금" 옵션, 플레이헤드 이동 단축키. GoCue: 선택=스탠바이. 중.
47. **오디션** — Alt+Space로 대체 출력(헤드폰 등)으로 재생, "항상 오디션" 모드. 없음. 중. 의존 13.
48. **워크스페이스 열 때/닫을 때 큐 자동 시작** — 소.
49. **깨진 큐 경고·파일 다시 찾기** — 상태 아이콘(파일 없음·패치 없음·플러그인 없음·슬라이스 전부 0 등) + 경고 창 + 없어진 파일 검색/재연결 도구. GoCue: 파일 없음 빨강만. 중.
50. **상태 아이콘 열** — 스탠바이·재생·일시정지·로드됨·테일 진행·깨짐·경고·깃발·오디션 중. GoCue: 일부. 소.

## G. 그룹·카트·기타 큐

51. **그룹 큐** — 타임라인(동시 시작 + 타임라인 에디터)·플레이리스트(순차, 크로스페이드·루프·셔플·2차 트리거로 다음/이전)·첫 큐 시작 후 진입·첫 큐 시작·랜덤(라운드로빈). 없음. 대.
52. **큐 카트** — 버튼 그리드(1×1~15×15, 최대 225개), 플레이헤드 없음, 샘플러/패드 방식. 없음. 대.
53. **디밴프 큐** — 무한 루프 중인 슬라이스가 끝나는 지점에서 깔끔히 빠져나옴, 다음 큐 동시 시작·대상 정지 옵션. 없음. 중. 의존 5.
54. **트랜스포트 큐 등** — 시작/정지/일시정지/로드/리셋을 큐로, GoTo·대기·메모·아밍/디아밍·타겟 큐. 없음. 중.
55. **여러 큐 리스트** — 리스트 무제한, 리스트별 플레이헤드, 탭 전환. 없음. 중.
