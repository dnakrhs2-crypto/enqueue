# LiveMix 설계 (2026-09-04)

방송용 라이브 마이크 VST3 호스트. DAW 없이 ASIO 오디오 인터페이스의 입력에 VST3 플러그인을 걸어 출력으로 내보낸다.
결정 사항은 전부 gom과의 대화(2026-09-04)에서 나온 것이고, 시안은 `바탕화면\LiveMix 시안\1 다크 콘솔*.png` 기준.

## 1. 목표와 범위

- **한다**: ASIO 장치 하나의 입력·출력 전부 사용. 마이크 채널(최대 8) → VST3 체인 → 마이크 ON/OFF → 출력(마스터 / 직접 출력 / 둘 다).
  FX 채널(리버브 같은 공간계, 여러 개) → 각 마이크 채널의 "이펙터" 칸에서 보내는 양(0~100 %)과 프리/포스트.
  마스터 채널(항상 하나) → VST3 체인 → 메인 출력 쌍. 세션 저장/불러오기, 자동 저장. 최소화해도(트레이) 계속 동작.
  온라인 백업(WebDAV, 시놀로지). 창 크기에 따라 카드가 3단계로 접히는 반응형 배치.
- **안 한다**: 게인·페이더(채널 레벨은 항상 0 dB, 레벨은 플러그인에서), 녹음, 팬, EQ/게이트 내장(플러그인으로), ASIO 외 드라이버(WASAPI 등), MIDI, 여러 장치 동시 사용.

## 2. 용어 (UI 문구)

마이크 채널 / 마이크 ON·OFF(불) / VST3 체인 / 이펙터(FX 채널로 보내는 양, 프리·포스트) / FX 채널 / 마스터 / 출력(마스터·직접 출력) / 세션 / 온라인 백업.
"뮤트"·"게인"·"AUX"·"센드/리턴" 같은 말은 화면에 쓰지 않는다.

## 3. 오디오 그래프

```
ASIO 입력 i (모노 1개 또는 스테레오 쌍) ─► [프리 탭] ─► 채널 VST3 체인 ─► [포스트 탭] ─► 마이크 ON/OFF (5 ms 램프)
      ─► 마스터 버스(합)                                            └► 직접 출력 쌍 (선택)
      각 FX 채널: Σ(채널 샌드 × 양) ─► FX VST3 체인 ─► 돌아오는 양 ─► 마스터 버스 (또는 직접 출력)
      마스터 버스 ─► 마스터 VST3 체인 ─► 메인 출력 쌍
```

- 프리 = 체인 전 원음을 보냄, 포스트 = 체인 거친 소리를 보냄. **마이크 OFF면 샌드도 끊긴다.**
- 모노 채널은 스테레오 버스 양쪽에 같은 신호. 스테레오 입력 쌍은 L/R 그대로.
- 채널·FX·마스터 체인은 `PluginChain`(앤큐 코어) 그대로: 순서, 바이패스, 상태 저장, 예외 시 우회(faulted), 테일.
- 지연 = ASIO 버퍼(입력 + 출력)만. 플러그인 지연 보정(PDC)은 하지 않는다(라이브라 그대로 들리는 게 맞다). 상단에 ms로 표시.
- 미터: 채널 입력(포스트 ON/OFF 전), FX, 마스터 L/R. 피크 홀드 1.5 s. 원자값으로 UI에 전달.
- 콜백은 락 없이: 파라미터(ON/OFF, 샌드 양, 라우팅)는 원자값, 체인 편집은 `PluginChain` 내부 락(앤큐와 동일), 채널 추가/삭제는 새 그래프를 만들어 교체(스왑 포인터, 옛 그래프는 메시지 스레드에서 해제).
- 장치가 끊기거나 샘플레이트가 바뀌면 체인 재준비, 상단에 상태 표시, 재연결 시 자동 재시작.

## 4. 데이터 모델 (세션 파일 `.livemix`, JSON, UTF-8)

```
{ "app": "LiveMix", "version": 1, "name": "방송 세팅 A",
  "device": { "name": "Focusrite USB ASIO", "bufferSize": 256, "sampleRate": 48000 },
  "channels": [ { "id": uuid, "name": "곰 마이크 (SM7B)", "on": true,
                  "input": { "first": 0, "stereo": false },
                  "chain": [ PluginSlotState... ],
                  "sends": [ { "fx": uuid, "amount": 0.35, "pre": false } ],
                  "output": { "master": true, "direct": { "enabled": true, "first": 2 } } } ],
  "fx": [ { "id": uuid, "name": "리버브", "chain": [...], "returnAmount": 1.0, "output": {...} } ],
  "master": { "chain": [...], "output": { "first": 0 } },
  "ui": { "window": "...", "fxPanelOpen": false } }
```

- 저장은 앤큐와 같은 검증된 원자적 저장(임시 파일 → 바이트 검증 → 교체). 미래 버전 파일은 열지 않는다.
- 자동 저장: 변경 후 10 초, 그리고 종료 시. 마지막 세션은 다음 실행 때 자동으로 열리고 오디오도 바로 시작된다.
- 플러그인 상태는 세션 저장 때 `getStateInformation`으로 담는다(앤큐 `captureLivePluginStates`와 같은 방식).

## 5. UI (시안 "1 다크 콘솔")

- **상단 바**: 로고(빨간 ON 타일 + LiveMix) · 세션 이름(저장 상태) · ASIO 장치 선택 · 샘플레이트·버퍼·지연 · DSP 부하 · [세션] [FX 채널 n] [온라인 백업] [설정].
- **채널 카드(가로, 추가할 때마다 아래로)**: 번호+이름(편집) · 마이크 ON/OFF 버튼(불) · 입력 선택 · VST3 체인 요약(①→②→③, "체인 열기", "+ 추가") · 이펙터(FX 채널마다 한 줄: 큰 페이더 + % + 프리/포스트) · 출력(마스터 칩, 직접 출력 칩) · 입력 미터.
  마이크 OFF면 카드가 흐려진다. 카드 삭제는 이름 옆 메뉴(···)에서.
- **마스터 카드**: 리스트 아래에 고정. 체인 요약 · 지연 · 메인 출력 쌍 · L/R 미터.
- **FX 채널 패널**(상단 버튼 → 오른쪽 서랍): FX 탭(추가/이름/삭제) · 체인 · 돌아오는 양 · 출력 · 미터 · 이 FX로 보내는 마이크 목록.
- **VST3 체인 패널**(카드의 "체인 열기" → 오른쪽 서랍): 세로 목록 ≡ 드래그로 순서 변경 · 켜짐/바이패스 스위치 · 열기(플러그인 창) · 삭제 · "+ 플러그인 추가".
  플러그인 추가 메뉴는 **제조사별**로 묶어서(앤큐와 같음).
- **반응형**: 창 폭 ≥ 1180 → 4열, 1180 미만 → 2행(이름·체인 / 이펙터·출력), 800 미만 → 1열 세로. 카드 리스트는 스크롤.
- **트레이**: 최소화하면 트레이로(설정으로 끌 수 있음), 트레이 아이콘 더블클릭으로 복귀, 메뉴에 마이크 전체 ON/OFF · 열기 · 종료. 닫기 버튼 = 트레이로(설정).
- 글꼴·색은 `UiUtils.h` Palette 방식으로 한 곳에(앤큐 규칙 동일). 다크 콘솔 팔레트: 배경 #15171B, 카드 #1F2228, 선 #2F343C, 글자 #F1F2F4, 보조 #98A0AB, 강조 #4C8DFF, 램프 #35D07F, 브랜드 빨강 #E5302D.

## 6. 설정

ASIO 장치(ASIO 타입만 나열) · 버퍼 크기(ASIO 제어판 열기) · Windows 시작 시 실행 · 최소화/닫기 시 트레이 · 자동 저장 간격 · 온라인 백업(WebDAV 주소, 폴더, 사용자, 비밀번호 저장 여부).

## 7. 온라인 백업

- WebDAV `PUT` (HTTPS, Basic 인증) — 시놀로지·QNAP·넥스트클라우드 공통. 기본값은 gom의 시놀로지(WebDAVServer 5006).
- 버튼 → 비밀번호 입력 창(저장 체크 시 Windows 자격 증명 관리자) → 먼저 세션 저장 → `<폴더>/<PC 이름>/<세션 이름>_<yyyy-MM-dd_HHmmss>.livemix` 업로드 → 결과 상태 표시. 실패해도 로컬 세션은 그대로.
- 백그라운드 스레드에서 전송, 오디오와 무관.

## 8. 코드 위치와 배포

- 앤큐 저장소(`gocue` / 워크트리 `gocue-phase6`) 안의 **두 번째 앱 타깃** `LiveMix`(`livemix/` 폴더). 코어(`GoCueCore`: PluginHost, PluginChain, PluginWindows, 설정 저장, 원자적 저장, 업데이터)를 그대로 링크. 새로 쓰는 것 = `MixEngine`(그래프), `MixSession`(모델/직렬화), UI, 백업, 트레이.
- 빌드·테스트는 한 번(`EnqueueTests`에 LiveMix 테스트 추가: 오프라인 렌더로 라우팅·샌드·ON/OFF·세션 왕복 검증).
- 배포: `LiveMix-Setup-x.y.z.exe`(Inno, 설치 폴더·AppId 별도), WinSparkle 업데이트(별도 appcast), GitHub 저장소 `dnakrhs2-crypto/livemix`에 릴리스, 사이트 `곰튀김.com/livemix/`. `tools/release.py`에 `--app livemix` 옵션.
- VST3 표기: 화면·문서에 "VST3"를 일반 글자체로만 쓰고, 정보 창에 "VST is a trademark of Steinberg Media Technologies GmbH" 표기.

## 9. 단계 (각 단계 끝에 테스트 통과 + 코덱스 리뷰)

1. `MixEngine` + `MixSession` + 오프라인 테스트(라우팅, 프리/포스트 샌드, ON/OFF 램프, 직접 출력, 미터, 세션 왕복).
2. 창·상단 바·채널 카드·마스터 카드·반응형 배치·미터 표시, ASIO 장치 연결.
3. VST3 체인 패널(드래그 순서·바이패스·플러그인 창·제조사별 메뉴), FX 채널 패널.
4. 세션 저장/열기/자동 저장/최근/시작 시 복원, 트레이, Windows 시작 시 실행, 설정 창.
5. 온라인 백업(WebDAV).
6. 설치기·업데이터·사이트, 코덱스 최종 리뷰, 0.1.0 배포.
