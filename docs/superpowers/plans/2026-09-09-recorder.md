**설계와 달라진 결정 및 후속 계약:**

1. 모델 필드를 추가하지 않고 `media/imports/<asset-id>/.import-info.json`에 원본 포맷, hash, raw/presentation/reader 실제 길이, 앞뒤 skip, MF priming 계수와 근거를 저장한다. 고정 SDK의 FFmpeg decoder는 길이/손상/skip 검증에만 사용한다. 캐시를 만드는 PCM은 지정된 JUCE/MF reader에서 읽는다. MF의 무음 오류 처리를 그대로 믿지 않도록 별도 native MF 순회에서 오류·EOF·실제 프레임 수를 확인한다.
2. 자유 함수 `commitImportedAudio`는 라운드 08 `performEdit`가 `RecorderProject` 작업 사본의 `EditState` base를 전달하는 구현에 의존한다. 그 사본에서 registry와 track을 함께 변경하여 한 revision/notify로 게시한다. 이 결합을 코드에 명시했으며 실패/undo/redo를 검사했다. 문서에 일반 registry+edit transaction API가 생기면 이 함수만 교체한다.
3. 공유 MF의 2,048샘플 seek preroll만으로 위 fixture가 순차 디코드와 같아지지 않았다. `media/AudioImport.cpp`의 래퍼에서 앞으로는 순차 decode하고 뒤로는 reader를 재생성한다. 이 원본 seek는 worker용이며 긴 파일에서 느릴 수 있다. 타임라인 재생은 완성된 PCM cache를 seek해야 한다. 공유 reader는 수정하지 않았다.
4. 파생 캐시는 완성된 WAV·peaks를 세대 폴더에 두고 검증된 manifest를 원자 교체한다. 이전 캐시 세대의 정리는 후속 cache GC 범위이며 원본/등록 asset은 삭제하지 않는다. `AudioImportPanel`은 host가 프로젝트 폴더·플레이헤드·녹화 상태를 전달하고 `onImported`를 받는 독립 컴포넌트다.
5. 쓰기 허용 범위 때문에 이 세션 증거는 Git 제외 `out/r16-evidence/import.json`, `out-r16-{configure,build,audio-import,ctest,probe}.log`에 보관했다. 원계획의 저장소 밖 영구 증거 디렉터리로 복사하지 않았다.

**미확인:** 실제 DRM 보호 파일, 다른 Windows/codec 조합, ASIO 청취와 녹화 중 부하, 긴 파일/4GiB 초과 import, 패널 실제 클릭 흐름, PeakCache/MediaIndex·MainComponent 통합. 컷 UI/RenderPlan과 최종본 '완성 오디오' source mask는 해당 후속 라운드에서 연결해야 한다.

- [ ] 실제 signed appcast 시험 feed 또는 통제된 fixture로 설치본 업데이트·진행 중 종료 지연·재실행·제거 후 사용자 프로젝트 보존을 검증한다. 기존 앱이 Recorder 업데이트를 받지 않게 한다.
- [ ] 설계의 필수 gate와 실물 보고를 묶어 재현 가능한 결과를 검토한다. SDK·driver·OS·장치 프로파일·사용자 흐름·제한·복구 절차를 릴리스 자료에 반영한다.

**완료 기준:** 필수 P0/원본/더빙/편집/내보내기/완료상태 복구/라이선스 gate 통과, 설치된 DLL만으로 실행, source/고지 링크·다른 앱 링크 검증, 사용자 프로젝트 비삭제. 검증하지 않은 OS·정전·인터페이스 조건은 지원 보장으로 표시하지 않음. 이 계획의 최종 산출은 게시 가능한 검증 묶음이며 현재 문서 세션이 게시 실행을 뜻하지 않는다.

**검증:** B+G 및 신규 배포 smoke 도구·clean PC 수동 절차.

```powershell
python -B tools/recorder/validate_release.py --bundle '.\release\recorder' --report "$recEvidence\r34\release.json"
& $recProbe installed-smoke --installed-exe-file "$recEvidence\installed-exe.txt" --devices "$recEvidence\studio-devices.json" --report "$recEvidence\r34\installed.json"
```

`installed-exe.txt`는 clean PC에서 실제 설치된 exe의 절대 경로를 기록한 입력이다. 설치 폴더를 추측해 실행하지 않는다. 이 명령은 설치본 기능 smoke와 결과 수집용이며 사용자 파일 자동 삭제/전체 PC 정리를 하지 않는다.

**산출 파일:** `tools/recorder/validate_release.py`, `recorder/tools/InstalledSmoke.cpp`, `docs/validation/recorder/install-update.md`, 최종 `release-gates.md`, `recorder/README.md`의 운영/복구 안내, 검증된 installer·소스·고지·manifest·appcast/site용 자료. 잔여 수정은 해당 파일/회귀 결과를 함께 기록한다.
