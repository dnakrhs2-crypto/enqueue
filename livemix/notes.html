바뀐 점

버전별 변경 사항. 최신 버전이 맨 위입니다.

LiveMix 0.3.1

  • 세로(좁은) 창 정리. 폭이 좁으면 마스터 카드가 짧은 형태(머리줄에 메인 출력, 체인 줄, 미터 줄)로 바뀌고, 창이 낮아 마이크 카드 자리가 모자라면 마스터가 한 줄(미터·체인 열기·메인 출력)로 접힙니다. 이제 420×720 최소 크기에서도 마이크 카드가 보입니다.
  • 서랍. 폭 1100 미만에서는 체인·FX 서랍이 창 전체 폭으로 열리고(좁은 옆 칸 대신), Esc로 닫힙니다. FX 탭은 몇 개든 전부 누를 수 있고, 탭을 바꾸면 서랍 높이가 그 FX의 체인에 맞게 다시 잡힙니다.
  • 휠 스크롤. 마이크 카드의 '보내는 양'과 FX의 '돌아오는 양' 슬라이더 위에서 휠을 굴려도 값이 바뀌지 않습니다 (스크롤만 됩니다).
  • 뮤트그룹 배지. 뮤트 핫키를 눌러도 상단 바의 줄 수가 바뀌지 않습니다 (배지 자리를 늘 비워 둡니다). 좁은 창에서는 배지가 첫 줄 오른쪽에 붙어 장치 상자를 밀지 않습니다.
  • 창 위치. 처음 여는 창과 저장된 창 위치가 화면 안에 맞춰지고, 플러그인 관리 창·플러그인 편집 창·설정 창도 메인 창이 있는 화면 안에 열립니다. 설정 창은 다른 창을 막지 않고, 화면이 낮으면 안에서 스크롤됩니다. 온라인 백업 창은 좁으면 로그인 줄이 두 줄이 됩니다.
  • 작은 것들. 상태줄의 오류 색이 시간이 지나면 돌아오고, 좁은 창에도 '최소화·X → 트레이' 안내가 남고, 서랍·알림의 닫기 버튼이 커졌고, 잘린 플러그인 이름은 마우스를 올리면 전부 보입니다. 화면 밖의 마이크 카드는 미터를 그리지 않습니다.
  • VST2 스캔. 'VST2 스캔'을 누르면 'VST2 플러그인 사용'이 저절로 켜지고 바로 스캔합니다 (버튼이 회색으로 죽어 있지 않습니다).

LiveMix 0.3.0

  • 메뉴바. 세션 · 온라인 백업 · 설정 · 도움말이 위쪽 메뉴로 갔습니다. 그 자리에는 FX 채널과 플러그인 관리 버튼이 있습니다.
  • 플러그인 관리 창. 스캔한 플러그인 목록에 '사용' 스위치가 있어, 끈 플러그인은 '+ 추가' 메뉴에서 빠집니다. VST3 스캔 · VST2 스캔 버튼, 목록에서 빼기.
  • VST2 플러그인 (선택). 플러그인 관리 창의 'VST2 플러그인 사용'을 켜야만 VST2를 스캔·사용합니다. 기본은 꺼짐입니다. 꺼 두면 세션에 든 VST2 자리는 비워 둡니다. 스위치는 이제부터 여는 세션과 넣는 플러그인에 적용되고, 이미 열어 둔 세션은 다시 열어야 반영됩니다 (스위치를 바꾸면 다시 열기를 제안합니다).
  • 플러그인 프리셋. 플러그인 관리 창에서 플러그인을 1. 2. 3. 순서로 골라 프리셋을 만들고(목록 위 검색칸으로 이름·제조사 검색), 이름 바꾸기 · 삭제 · 파일로 저장 · 파일에서 불러오기가 됩니다. 어느 체인에서든 '+ 추가 > 프리셋 불러오기'로 한 번에 넣고(바꾸기 / 뒤에 추가), '+ 추가 > 이 체인을 프리셋으로 저장'으로 지금 체인을 설정째 프리셋으로 둡니다. 파일은 내 문서\LiveMix\플러그인 프리셋.
  • 프리셋 온라인 백업. 온라인 백업 창의 '플러그인 프리셋 백업'이 이 PC의 프리셋을 전부 계정 폴더에 올리고(읽을 수 없는 파일이 있으면 그 파일 이름을 알리고 멈춥니다), 목록에서 프리셋을 골라 '불러오기'하면 프리셋 폴더로 내려옵니다.
  • 계정 만들기 창. '계정 만들기'를 누르면 등록 창이 뜨고, 아이디와 비밀번호를 넣어 등록하면 '등록완료!'가 뜨며 확인을 누르면 창이 닫히고 바로 로그인됩니다.

LiveMix 0.2.0

  • 뮤트그룹 2개. 마이크 카드의 '출력' 옆 뮤트그룹 칩을 켠 마이크들이 마이크 뮤트그룹, FX 채널의 '출력' 옆 칩을 켠 FX들이 FX 뮤트그룹입니다. 설정에서 정한 핫키 하나로 그룹 전체를 뮤트/해제합니다. 최소화하거나 트레이에 있어도 동작합니다. 트레이 메뉴에서도 토글할 수 있습니다.
  • 뮤트 중에는 위쪽에 빨간 표시가 뜨고, 마이크 카드의 ON/OFF 버튼과 FX 리턴 값도 빨갛게 '뮤트'를 보여 줍니다. 해제하면 각 채널의 원래 ON/OFF·리턴 값이 그대로 돌아옵니다.
  • 전역 핫키는 다른 프로그램의 같은 키를 가로채므로 F 키나 Ctrl+Alt 조합을 권합니다. 글자·숫자 키는 Ctrl/Alt/Shift와 함께만 됩니다.
  • 세로 모드. 창을 좁게(폭 1000px 미만) 하면 위쪽 막대가 두 줄, 700px 미만이면 세 줄로 접히고, 마스터 카드는 세로로 쌓이며, 체인·FX 서랍은 창 전체 폭을 씁니다. 창 최소 폭이 720px에서 420px로 줄어 세로로 긴 창이 됩니다.
  • 안정성: 플러그인 설정을 읽지 못하면 저장을 실패로 알립니다(모르고 옛 설정을 저장하지 않음). 저장 중 값이 계속 바뀌면 그렇다고 알립니다. 체인은 16개까지만 넣을 수 있습니다(17번째는 저장에서 사라졌음). 다시 열 수 없는 크기(32 MB 초과)의 세션은 저장·백업하지 않습니다. 준비 중 오류를 낸 플러그인은 빈 자리로 남기고 알립니다. 응답이 없는 플러그인은 건너뛰며 알립니다. 오디오 콜백은 편집 중인 플러그인 목록을 기다리지 않습니다. 시작 시 세션을 하나도 열지 못해도 기본 세션이 돌아갑니다. FX 서랍이 길어지면 스크롤됩니다. 트레이 아이콘이 탐색기 재시작 뒤에도 그대로입니다.

LiveMix 0.1.9

  • 안정성 점검 반영. 켜질 때 저장된 세션이 다 불러와지기 전에는 마이크 소리가 출력으로 나가지 않습니다. 저장·백업 중에 플러그인이 느리게 답해도 오디오가 멈추지 않습니다. 오디오 인터페이스가 끊겼다 돌아오다 실패하면 "오디오 멈춤"으로 정직하게 표시하고, 세션의 장치를 다시 엽니다.
  • 플러그인이 잘못된 값(NaN)을 내거나 오류를 내면 그 자리만 소리를 그대로 통과시키고 위쪽 띠로 알려 줍니다. 플러그인을 만들거나 준비하거나 설정을 읽고 쓰는 중의 오류도 프로그램을 멈추지 않습니다.
  • 샌드·리턴 페이더를 움직일 때 '틱' 소리가 나지 않도록 부드럽게 바뀝니다.
  • ASIO 제어판에서 버퍼를 바꾸면 장치를 다시 엽니다. 마이크 체인에 지연이 있는 플러그인이 있으면 알려 줍니다.
  • 저장 중에 플러그인 값이 바뀌면 한 번 더 저장합니다. 지나치게 큰 세션 파일·서버 응답은 읽지 않습니다. 종료 시 백업 스레드를 오래 기다리지 않습니다.
  • 글씨를 전체적으로 키웠습니다.
  • '+ 추가'를 누르면 플러그인 목록이 그 버튼 옆에 열립니다.
  • 단축키: Ctrl+S 저장, Ctrl+Shift+S 다른 이름으로 저장, Ctrl+N 새 세션. 세션 메뉴에도 표시됩니다. 이름을 고치는 중에 눌러도 고친 이름이 먼저 반영됩니다.
  • FX 채널 탭과 이펙터 칸에서 이름이 기본값(FX 1)일 때 "FX1 FX 1"처럼 두 번 나오던 것을 한 번만 보이게 했습니다.
  • 위쪽 '?' 버튼은 '정보'로, DSP 표시는 CPU로 바꿨습니다.
  • 트레이 아이콘이 검게 나오던 문제를 고쳤습니다.
  • 플러그인 칩이 여러 줄이 되면 카드(마스터 포함)가 그만큼 늘어나 버튼과 겹치지 않습니다.

LiveMix 0.1.7

  • 자동 저장을 없앴습니다. 세션 파일은 '세션 > 저장'을 누를 때 씁니다. 프로그램을 끌 때와 온라인 백업을 올리기 직전에는 지금처럼 바뀐 내용을 파일에 써 둡니다. 설정의 '자동 저장 (초)' 칸도 없어졌습니다.

LiveMix 0.1.6

  • 설정의 스위치 이름을 'OFF시 플러그인 OFF'로 바꿨습니다. 마이크를 OFF하면 그 채널의 플러그인도 멈추는 기능(0.1.5)의 스위치입니다.

LiveMix 0.1.5

  • OFF인 마이크는 플러그인 계산도 멈춥니다. 마이크를 OFF하면 그 채널의 플러그인 처리를 건너뛰어 CPU를 쓰지 않습니다(케이크워크의 아카이브와 같은 효과). 켜면 바로 다시 돕니다. 딜레이·리버브처럼 시간이 걸리는 플러그인을 마이크 체인에 직접 걸어 둔 경우 켜는 순간 OFF 전 소리가 잠깐 날 수 있어, 설정에서 끌 수 있습니다(기본: 켜짐).
  • OFF인 동안 채널 미터는 마이크 원음 레벨을 보여 줍니다.

LiveMix 0.1.4

  • 온라인 백업 계정. 백업 창에서 아이디와 비밀번호를 정해 '계정 만들기'를 누르면 계정이 생기고, 그 뒤로는 로그인해서 씁니다. 목록에는 로그인한 계정의 백업만 보이고, 올리기('지금 세션 백업')와 불러오기('선택한 백업 불러오기', 더블클릭도 됨)도 그 계정의 아이디·비밀번호로만 됩니다. NAS 계정은 더 이상 필요 없습니다.
  • '이 PC에 기억'을 켜면 아이디와 비밀번호가 이 PC에 저장되고(Windows 자격 증명 관리자), 끄면 지워집니다.
  • 설정에 있던 백업 주소·폴더·사용자 칸은 없어졌습니다. 백업 서버는 프로그램에 들어 있습니다.
  • 불러온 백업은 문서\LiveMix 폴더에 파일로 남습니다.

LiveMix 0.1.3

  • 온라인 백업 창. 위쪽 '온라인 백업' 버튼이 창을 엽니다. 아이디와 비밀번호를 넣고 '목록 보기'를 누르면 시놀로지에 있는 백업 목록이 나오고, '지금 세션 백업'으로 올리고, 목록에서 골라 '선택한 백업 불러오기'(더블클릭도 됨)로 내려받아 그대로 세션으로 엽니다. 목록·올리기·내려받기 모두 그 아이디와 비밀번호로만 됩니다. '이 PC에 기억'을 켜면 Windows 자격 증명 관리자에 저장되고, 끄면 창을 닫을 때 지워집니다.
  • 백업은 각 계정의 홈 폴더 안 LiveMix 백업/PC이름/크리에이터_날짜시간.livemix 로 저장됩니다. 설정의 '사용자'·'비밀번호 기억' 칸은 백업 창으로 옮겼습니다.
  • 불러온 백업은 문서\LiveMix 폴더에 파일로 남습니다(같은 이름이 있으면 번호가 붙음).
  • 다른 PC에서 만든 세션의 플러그인이 이 PC에 없을 때의 안내가 한국어로 나옵니다. 그 자리는 비워 두고(소리는 그냥 통과) 저장된 설정은 세션에 그대로 남습니다.

LiveMix 0.1.2

  • 창 크기를 못 바꾸던 문제. "ASIO 장치를 열지 못했습니다" 같은 안내가 대화 상자로 떠 있는 동안에는 창 가장자리를 끌어도 크기가 바뀌지 않고 마이크 버튼도 눌리지 않았습니다. 이제 안내는 창 안 위쪽의 띠로 나옵니다(✕로 닫음, 길면 스크롤). 창은 언제나 모서리·가장자리로 줄이고 늘릴 수 있고, 오른쪽 아래 구석의 손잡이로도 조절됩니다.
  • 이미 켜져 있는데 아이콘을 또 실행하면 죽던 문제. 두 번째 실행은 열려 있는 창을 앞으로 가져오고 조용히 끝납니다. 이전에는 종료 중 오류로 죽어 Windows 오류 기록이 남았습니다.
  • 세션 파일을 더블클릭해 열다가 실패하면 그 안내가 남습니다. 이전에는 마지막 세션이 대신 열리면서 안내가 사라졌습니다. 세션 경고와 장치 안내가 같이 있으면 둘 다 보입니다.
  • 저장 실패 안내도 대화 상자 대신 띠로 나옵니다.

LiveMix 0.1.1

  • FX 채널 모노 스위치. FX 채널 패널의 출력 칸에 "모노" 버튼이 생겼습니다. 켜면 그 FX의 소리를 좌우 합쳐(절반 크기로 더해) 양쪽에 똑같이 내보냅니다. 세션에 저장됩니다.

LiveMix 0.1.0

첫 공개 버전입니다. DAW 없이 ASIO 인터페이스의 마이크 입력에 VST3 플러그인을 걸어 방송에 쓰는 프로그램입니다.

  • 마이크 채널(최대 8개): ASIO 입력 하나 또는 스테레오 쌍 → VST3 체인 → 마이크 ON/OFF → 출력. 채널 이름은 더블클릭으로 바꿉니다.
  • VST3 체인: 카드에서 ①→②→③ 순서로 보이고, "체인 열기"에서 드래그로 순서 변경·켜짐/바이패스·플러그인 창 열기. 플러그인 추가 메뉴는 제조사별.
  • FX 채널(최대 4개): 채널마다 보내는 양(%)과 프리/포스트. FX 채널 패널에서 체인·돌아오는 양·출력·보내는 마이크를 봅니다.
  • 출력: 마스터 / 장치 출력 쌍으로 직접 / 둘 다. 마스터에는 자체 VST3 체인과 메인 출력 쌍.
  • 세션: 플러그인 상태까지 .livemix 파일로 저장. 변경 후 자동 저장, 다음 실행 때 마지막 세션이 열리고 오디오가 바로 시작됩니다.
  • 트레이: 최소화(또는 닫기)하면 트레이에서 계속 동작. 트레이 메뉴에서 마이크 전부 ON/OFF·열기·종료. Windows 시작 시 실행 옵션.
  • 온라인 백업: 크리에이터 이름을 넣으면 세션을 NAS(WebDAV)의 /LiveMix 백업/PC이름/크리에이터_날짜시간.livemix로 올립니다. 주소는 https만 받고, 파일은 임시 이름으로 올린 뒤 제 이름으로 바꾸므로 끊긴 업로드가 백업 이름으로 남지 않습니다. 기억한 비밀번호는 서버·사용자별로 따로 보관합니다.
  • 세션의 장치: 세션을 열면 저장할 때 쓰던 ASIO 장치·샘플레이트·버퍼로 엽니다. 그 장치가 없으면 지금 장치로 동작하면서 알려 주고, 세션 파일의 장치 이름은 바꾸지 않습니다.
  • 저장하지 않은 세션: 새 세션·열기·종료 전에 저장되지 않은 변경이 있으면 먼저 저장하고(파일이 없으면 저장할지 물어보고) 넘어갑니다. 플러그인 창에서 돌린 노브도 변경으로 칩니다.
  • 안전 모드: Shift를 누른 채 실행하거나 --safe-mode로 실행하면 장치와 플러그인을 불러오지 않고 시작합니다(플러그인 설정은 세션에 그대로 남습니다). 플러그인 때문에 실행이 안 될 때 쓰세요.
  • 창 폭에 따라 카드가 4열 → 2행 → 1열로 접힙니다. 미터는 채널·FX·마스터마다.
  • 업데이트는 프로그램 안에서 자동 확인(? → 업데이트 확인), 커뮤니티는 ? → 커뮤니티.
