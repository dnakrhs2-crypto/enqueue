LiveMix 0.1.0 다운로드

Windows 10/11 64비트 · 설치 파일은 GitHub 릴리스에서 받습니다.

설치 파일에 아직 코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 경고 창에서 추가 정보 → 실행을 누르면 설치가 진행됩니다.

주요기능

  • ASIO 지원 (ASIO가 없으면 사용이 불가능합니다.)
  • 인풋 채널 스테레오 기준 최대 4개 지원 (모노 8개)
  • FX 채널 최대 4개의 사용 가능 (프리페이더,포스트페이더 지원)
  • 라이브 방송에 최적화되어 어떤 DAW보다 가볍고 안정적인 시스템
  • 직관적인 마이크 ON/OFF 버튼과 샌드 조절 버튼

비용 : 완전 무료

요구 사항

운영체제
Windows 10 (1607) / 11, 64비트
오디오
ASIO 드라이버가 있는 오디오 인터페이스 (ASIO만 지원)
플러그인
VST3
설치
사용자 계정에 설치(관리자 권한 불필요). 업데이트는 프로그램 안에서 자동으로 확인합니다.
