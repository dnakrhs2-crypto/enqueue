라이브믹스 · 방송용 마이크 VST3 호스트

DAW 없이, ASIO 오디오 인터페이스의 마이크 입력에 VST3 플러그인을 걸어 바로 내보냅니다. 마이크 채널·FX 채널·마스터, 세션 저장, 트레이에서 계속 동작.

LiveMix 다운로드 (곧 공개)

Windows 10/11 64비트 · 설치 파일은 GitHub 릴리스에서 받습니다.

설치 파일에 아직 코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 경고 창에서 추가 정보 → 실행을 누르면 설치가 진행됩니다.

기능

마이크 채널 (최대 8개)

ASIO 입력 하나(또는 스테레오 쌍)에 VST3 체인을 걸고, 마이크 ON/OFF 불로 켜고 끕니다. 게인·페이더 없이 항상 0 dB.

VST3 체인

순서대로 통과. 체인 패널에서 드래그로 순서 변경, 켜짐/바이패스, 플러그인 창 열기. 제조사별 메뉴로 추가.

FX 채널

리버브·딜레이 같은 공간계는 FX 채널로. 채널마다 보내는 양(%)과 프리/포스트를 큰 페이더로.

출력 라우팅

채널을 마스터로, 장치 출력 쌍으로 직접, 또는 둘 다. OBS에서 따로 받기 좋습니다.

세션

플러그인 상태까지 .livemix 파일로 저장, 자동 저장, 다음 실행 때 마지막 세션과 오디오가 바로 켜집니다.

트레이 · 온라인 백업

최소화해도 트레이에서 계속 동작. 크리에이터 이름만 넣으면 세션을 NAS(WebDAV)로 백업.

요구 사항

운영체제
Windows 10 (1607) / 11, 64비트
오디오
ASIO 드라이버가 있는 오디오 인터페이스 (ASIO만 지원)
플러그인
VST3
설치
사용자 계정에 설치(관리자 권한 불필요). 업데이트는 프로그램 안에서 자동으로 확인합니다.
